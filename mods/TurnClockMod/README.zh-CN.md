# 回合时钟（TurnClockMod）

在 SpeedHackMod 的 `native` 或 `unity` 模式下，按真实时间补偿客户端倒计时，不改变动画、战斗或全局时钟倍率。

## 补偿范围

- 自己的操作窗口，以及可选的其他玩家倒计时显示。
- 选人界面的自动确认倒计时。
- 结算界面的自动翻页倒计时。
- 房间等待、超时退出与房主转让倒计时。
- 剧情自动播放的翻页倒计时。

本模组只调整客户端计时，不延长服务器允许的操作时间，也不修改服务器规则。

## 与变速模式配合

- **native 模式**：补偿原生时钟倍率。
- **unity 模式**：对使用游戏时间的计时器，按原生倍率与当前 Unity 帧时间缩放共同补偿；对使用实时的计时器，只补偿原生倍率。
- Unity 帧倍率优先使用 `deltaTime / unscaledDeltaTime`，兼顾倍率切换当帧、暂停和 `maximumDeltaTime` 截断。接口不可用时回退到 `timeScale`，再不可用时只保留原生补偿。
- 无法识别计时器的实时／游戏时间标记时，保留原生补偿，不猜测 Unity 倍率。
- 原生状态缺失或无效时，只观察计时器、不写入补偿；有效状态恢复后继续补偿，不追溯修改未知期间的进度。

同一帧内，各计时器共用一次原生状态采样和一次 Unity 帧时钟采样；同一计时器即使由多个入口发现，也只处理一次。没有可用计时器或处于加载地图阶段时，不读取原生状态文件或 Unity 帧时钟。

## 配置

随包的 `config.json` 带有行内注释及简中、繁中、英语、日语字段说明。已有配置可继续使用，无需替换整份文件。

| 字段 | 默认值 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `otherPlayers` | `true` | 其他玩家倒计时按真实时间显示 |
| `heroSelect` | `true` | 选人倒计时 |
| `settlement` | `true` | 结算倒计时 |
| `roomWait` | `true` | 房间等待倒计时 |
| `storyAuto` | `true` | 剧情自动播放 |
| `dryRun` | `false` | 只观察和记录，不修改计时器 |
| `logWindow` | `true` | 记录倒计时窗口的补偿摘要 |
| `speedRefreshSeconds` | `0.2` | 原生倍率常规读取间隔，范围 `0.05–5` 秒 |
| `elapsedMember` | 空 | 手动指定已用时间成员；空值自动探测 |
| `startMember` | 空 | 手动指定计时起点成员；空值自动探测 |
| `clockMember` | 空 | 手动指定时钟成员；空值自动探测 |
| `durationMember` | `duration` | 倒计时长度成员 |

倍率异常时允许提前刷新原生状态，但两次读取至少间隔 `0.05` 秒。Unity 帧倍率单独采样，不受 `speedRefreshSeconds` 限制。

配置热重载会重新建立计时基准，并允许重新探测先前不可用的 Unity 时钟接口及计时成员。暂停期间不会主动解除游戏暂停；实时计时器仍按自己的时钟推进。
