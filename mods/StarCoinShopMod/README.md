# StarCoinShopMod（星币商店助手）

在主界面商城的「星币商店」推荐页提供一键顺序购买全部商品功能，带可配置的冷却间隔，免去逐个点击购买的繁琐操作。

## 功能特性

- **一键清空**：进入商城推荐面板后，点击标题旁的「一键购买」按钮或按下快捷键（默认 `F`），自动按顺序购买当前货架上全部 8 个每日物资。
- **冷却间隔**：每次购买之间等待设定的冷却时间（默认 0.8 秒），避免连续发包触发服务器限制或网络拥堵。
- **智能校验**：自动识别并优先领取免费商品；付费商品自动核对当前星币余额，余额不足时自动跳过并在日志中提醒；自动跳过已售罄与已拥有商品。
- **即时刷新**：全部商品处理完毕后自动刷新货架与背包状态，并在游戏内弹出完成通知。

## 配置选项 (`configs/StarCoinShopMod.json`)

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 总开关：开启星币商店一键购买功能 |
| `cooldownSeconds` | float | `0.8` | 每个商品购买之间的冷却间隔（秒，范围 0.2–5.0） |
| `quickBuyKey` | string | `"F"` | 商店界面一键购买快捷键 |
| `showButton` | bool | `true` | 是否在星币商店标题旁显示「一键购买」按钮 |
| `buttonOffsetX` | float | `0.0` | 「一键购买」按钮水平微调（像素，负数向左，正数向右） |
| `notifyOnComplete` | bool | `true` | 购买完成或终止时是否弹出游戏内通知 |
| `buySlot1` | bool | `true` | 自动购买第 1 格商品（通常为每日免费道具 1） |
| `buySlot2` | bool | `true` | 自动购买第 2 格商品（通常为每日免费道具 2） |
| `buySlot3` | bool | `false` | 自动购买第 3 格商品（通常为 50 星币道具 1） |
| `buySlot4` | bool | `false` | 自动购买第 4 格商品（通常为 50 星币道具 2） |
| `buySlot5` | bool | `false` | 自动购买第 5 格商品（通常为 300 星币道具 1） |
| `buySlot6` | bool | `false` | 自动购买第 6 格商品（通常为 300 星币道具 2） |
| `buySlot7` | bool | `true` | 自动购买第 7 格商品（通常为 300 星币徽章 1） |
| `buySlot8` | bool | `true` | 自动购买第 8 格商品（通常为 300 星币徽章 2） |
