# 岔路地块标记 ForkDirectionMod 1.1.0

在 PVE 地图三岔路口的三个相邻地块上，按原始邻接表顺序显示字母与地块 ID：A 红色、B 黄色、C 蓝色。例：11 的邻接表为 [10,52,12]，则在 10 上显示 A 10，在 52 上显示 B 52，在 12 上显示 C 12。不按 ID 数值排序，不排除角色来路，不显示箭头或左上角说明。

不存在、禁用、重复及指向自身的邻接项会过滤，过滤后恰好三个有效邻居才标记。0 号地块有效。共享于多个路口的地块会分行显示，并在括号中标出所属路口 ID。

每 0.5 秒检查地块状态及邻接顺序，标签每帧跟随相机，离开 PVE 或卸载模组时清理。标签不接收鼠标输入。

## 安装

需要 CesiumLoader SDK 2.5.0 或更高版本。将安装包中的 ForkDirectionMod 文件夹解压到游戏 AstralParty_ModLoader/mods/ 下，重启游戏。包内 DLL 与 PDB 为同次构建。

## 配置

修改模组目录的 config.json，重启后生效：

- enabled：显示开关，默认 true。
- fontSize：字母和编码字号，默认 24，范围 14–48。
- heightOffset：标签相对地块世界坐标的高度偏移，默认 0.8，范围 0–10。

旧配置中的 showLegend、showIds、arrowWidth 不再使用。界面始终不显示左上角说明，标签始终附带地块 ID。

许可：AGPL-3.0，与仓库内置模组一致。
