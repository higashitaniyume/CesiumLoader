# 消息停留时间 ChatDurationMod 1.0.0

战斗中的快捷消息与表情默认只显示几秒。开启变速后游戏时间走得更快，消息会在更短的真实时间里消失，往往来不及看清。

本模组按**真实时间**计算停留时长，默认 15 秒，可在配置里调整。变速倍率变化不会缩短停留时间。

## 安装

需要 CesiumLoader SDK 2.8.6 或更高版本。把 `ChatDurationMod` 文件夹解压到游戏 `AstralParty_ModLoader/mods/` 下，重启游戏。

## 配置

修改 `mods\ChatDurationMod\config.json`，保存后约 1 秒热重载：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关；`false` 时恢复游戏原版停留时长 |
| `durationSeconds` | `15` | 消息与表情停在屏幕上的秒数（真实时间），范围 1–300 |

```json
{
  "enabled": true,
  "durationSeconds": 15
}
```

## 说明

- 作用于战斗消息列表中的快捷消息和表情（队友发送的与本地发送的都包括）。游戏只在战斗消息列表中显示这些内容，本模组不改变发送方式。
- 消息列表容量有限；短时间连续收到很多条时，最早的消息仍会先被挤出列表。
- 关闭模组或把 `enabled` 改成 `false` 后，之后的消息恢复游戏原版停留时长，当前已显示的条目会立即收起。
- 只调整本机显示时长，不发送消息、不修改对局数据，也不影响其他玩家。
