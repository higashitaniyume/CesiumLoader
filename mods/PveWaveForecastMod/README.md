# PVE 波次预告

在 PVE 对局中，把「任务波次」的刷新回合、波次标题和刷新内容显示在地图上。

## 功能

- 读取当前地图与难度的波次表，按回合显示任务波次。
- 地图上标记即将刷怪的地块，并显示波次标题与怪物名称。
- 左上角显示本局全部波次列表，当前进度高亮。
- 怪物按类别区分：
  - 首领：红色，`首领·名字`
  - 精英：紫色，`精英·名字`
  - 普通：蓝色，`普通·名字`
- 配置没有给出精确地块时，标出所有怪物地块，并注明「位置随机」。

## 使用

1. 在玩具页启用「PVE 波次预告」。
2. 进入任意 PVE 合作挑战地图。
3. 默认不显示；按 `O` 打开预告，再按 `O` 关闭。
4. 打开后地图上会出现当前/下一波的地块标记；左上角显示完整波次表。

## 配置

| 字段 | 说明 | 默认 |
|---|---|---|
| `enabled` | 启动时是否显示（游戏内按 `O` 可切换） | `false` |
| `toggleKey` | 开关按键 | `O` |
| `fontSize` | 地图标记字号，14–48 | `22` |
| `heightOffset` | 标记相对地块的高度偏移（米），0–10 | `1.6` |
| `labelLift` | 标记额外上移像素，避免与岔路标记重叠，0–160 | `36` |
| `showSchedulePanel` | 显示左上角波次列表 | `true` |
| `showOnlyNextWave` | 只标记当前/下一波 | `true` |
| `showRandomLandHints` | 无精确地块时标出所有怪物地块 | `true` |
| `maxWaves` | 列表最多显示的波次数，1–20 | `8` |

## 覆盖范围

- 覆盖全部 PVE 合作挑战地图（82007 / 82008 / 82010 / 82012 / 82013 / 82014 / 82015 / 82016 / 82017）及各自难度档。
- 只显示任务事件波次，不包含随机补怪。
- 配置或已验证数据给出精确地块时直接标出；没有给出时标出该地图所有怪物地块，并注明「位置随机」。

## 说明

- 波次数据来自游戏配置的任务事件表，回合取事件的触发进度。
- 部分波次的配置直接给出精确地块；没有给出的波次会退化为「怪物地块 + 位置随机」。
- 只显示任务事件波次，不包含随机补怪。
