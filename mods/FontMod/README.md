# 系统字体（FontMod）

把游戏界面字体替换成电脑上已经安装的字体。

## 使用

1. 打开 Toys →「自定义」→「字体」。
2. 在卡片里挑一个字体（卡片预览就是该字体渲染的中文示例），点一下即可；有字重的字体（细体 / 粗体等）会在卡片下方列出可选的变体。
3. 游戏里立即生效，不用重启；点「恢复游戏默认」换回原字体。

选择结果写入 `mods/FontMod/config.json` 的 `fontFamily`，下次启动自动套用。

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关。关闭后立即恢复游戏默认字体。 |
| `fontFamily` | 空 | 系统字体家族名（如 `Microsoft YaHei`，带字重时如 `Microsoft YaHei UI Light`）。留空 = 游戏默认。一般由 Toys 写入。 |
| `applyToAllFonts` | `true` | `true` = 替换所有旧版界面字体（含标题/数字）；`false` = 只替换默认正文。 |
| `fallbackFonts` | 见下 | 逗号分隔的回退字体。用户字体缺字时按顺序取第一个包含该字符的字体。 |
| `checkCoverage` | `true` | 替换前用游戏文案的字符集检查缺字；缺字太多时保持游戏默认字体，避免整屏方块。 |

默认回退列表：`Microsoft YaHei,Microsoft YaHei UI,SimHei,SimSun,SimSun-ExtB,Yu Gothic,Meiryo,Microsoft JhengHei,Segoe UI Symbol`。

## 说明

- 字体必须是系统里已安装的字体；安装新字体后需要重启游戏才能在列表里看到。字体列表按游戏能识别的系统字体名列出；若配置里的名字游戏无法识别（例如手改配置写错名字），模组会保持游戏默认字体并在日志里写明原因，而不是静默换成回退字体。
- 变体能否在游戏内生效，取决于系统有没有把该字重注册成独立字体名（例如 `Microsoft YaHei UI Light`）。没有独立名字的字重不会出现在卡片里，避免选了却回退成常规体。
- 加载器自绘的浮层面板（如 F8 更新提示、PVE 面板）会跟随所选字体；游戏内预烘焙的 `_TMP` 标题与数字仍保持原样。
- 字体缺少某些字时游戏会画成方块。替换前会按游戏文案的字符集检查：缺字过多会拒绝替换并在日志里列出缺的字；缺几个字会照常应用并提示。换用覆盖更全的字体（思源黑体 / 微软雅黑 / Noto Sans CJK）通常可以避免。
- 玩家名等玩家自己输入的内容不在游戏字符集里，仍可能遇到字体没有的字。
- 替换的是游戏旧版动态字体（默认正文、部分界面字体）。带 `_TMP` 后缀的预烘焙字体（部分标题与数字）不在本模组范围内，会保持原样。
- 不同字体的字宽不同，个别定宽布局（按钮、姓名板、排行榜）可能出现换行或轻微位移，换回默认字体即可恢复。
- 切语言或重新登录后会自动重新套用。
