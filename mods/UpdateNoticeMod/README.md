# 加载器更新提示（UpdateNoticeMod）

加载器在后台检查到新版本后，在游戏里弹一个面板告诉你——不用开控制台，也不用去翻发布页。

## 面板内容

- 当前版本与最新版本：`3.8.4 → 3.8.5`
- 发布 tag 与发布日期
- 发布页地址（以及清单里带回来的更新说明）
- 三个按钮：
  - **打开发布页**：用默认浏览器打开该版本的 GitHub 发布页，下载与安装步骤在那里。
  - **忽略此版本**：把这个版本号写进本模组配置，该版本以后不再自动弹；出了再新的版本会重新提示。
  - **稍后再看**：关掉面板，下次启动游戏仍会提示。

面板只做提示与跳转，**不会**在游戏里下载或替换 `version.dll`——那个文件正被游戏进程占用，安装请用 AstralParty Toys 的「加载器」页或手动解压发布包。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `F8` | 打开 / 关闭面板（可在配置里改，填 `None` 关闭） |
| `Esc` | 关闭面板 |

面板固定在屏幕中心（参考分辨率 1920×1080），只有按钮区域接收鼠标点击，不挡游戏操作。

## 配置

配置文件位置：`<游戏目录>\AstralParty_ModLoader\mods\UpdateNoticeMod\config.json`，改完立即生效（不需要重启）。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关。关掉后不读检查结果、也不弹面板。 |
| `autoShow` | `true` | 发现新版本时启动后自动弹一次。关掉后只按快捷键显示。 |
| `showReleaseNotes` | `true` | 面板里显示发布清单的 `releaseNotes`。 |
| `toggleKey` | `"F8"` | 打开/关闭面板的快捷键。 |
| `ignoredVersion` | `""` | 「忽略此版本」记录的版本号；清空即恢复提示。 |

## 数据来源

加载器启动后在后台线程拉一次版本清单（GitHub Release 的静态 `version.json`），结果写到
`<游戏目录>\AstralParty_ModLoader\update\state.json`，并在控制台打一行 `[update]`。本模组只读那个文件，
所以：

- 模组自己不发起任何网络请求，也不需要联网权限；
- 检查结果、跳过原因、失败信息都能在控制台 `update` 命令里看到；
- 关掉加载器的 `updateCheckEnabled` 后，本模组不会弹任何东西（面板里会说明原因）。

如果控制台里能看到 `[update] 发现新版本 …` 但游戏里没弹面板，先确认 `enabled` 与 `autoShow` 为 `true`、
`ignoredVersion` 不是该版本号，再按一下 `F8` 手动打开。
