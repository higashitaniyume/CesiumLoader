# CharacterTransparencyMod（角色半透明）

按 `H`（默认）使游戏中的角色精灵半透明化（默认 36% 不透明度），方便在角色堆叠、站在关键地块或怪物格上时，清晰看清下方地块类型、图标与事件。

## 功能特性

- **按键半透明**：支持长按半透明（松开立即恢复）与点击切换两种模式。
- **模式切换开关**：通过 `holdMode` 开关切换“长按模式”与“点击切换模式”，默认为长按模式。
- **自定义不透明度**：可自定义半透明时的目标不透明度（默认 0.36 即 36%）。
- **零副作用还原**：松开或切换回正常时，精准还原角色原本的透明度，与角色隐身技能互不冲突。
- **输入保护**：聊天框输入文字或处于输入焦点时不触发热键。

## 配置项 (`configs/CharacterTransparencyMod.json`)

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | 总开关，关闭后不响应热键 |
| `toggleKey` | string | `"H"` | 快捷键，支持字母、功能键与特殊按键 |
| `holdMode` | bool | `true` | 模式开关：`true` 为长按切换（按住半透明，松开恢复）；`false` 为点击切换（按一下切换状态） |
| `opacity` | number | `0.36` | 半透明时的目标不透明度（0.0 ~ 1.0 或百分比 0 ~ 100） |
| `holdSeconds` | number | `0.0` | 长按模式触发所需的按住时长（秒），默认 0.0 为即时生效 |
