# 多语言支持（LanguageUnlockMod）

在国服客户端启用游戏设置里本来就列出的 **英文 / 日文 / 繁中** 三个选项。

国际服客户端原生支持这 4 种语言，模组检测到非国服会自动退出、不做任何改动。

## 使用

1. 启动游戏，打开 **设置 → 屏幕 → 语言**。
2. 选择要用的语言，确认后游戏会重新登录。
3. 想要恢复简中，在同一处选回「简体中文」即可。

选择会保存到 `mods/LanguageUnlockMod/config.json` 的 `language` 键（`zh` / `en` / `ja` / `tc`），下次启动自动应用。
启动时游戏会先以简中进入登录界面，模组初始化后再自动重登一次切到目标语言。

## 说明

- 正文（卡牌、技能、道具、剧情、消息等）来自国际服同版本的 64 张 STR 翻译表，按 Id 写入；国服以后新增、国际服还没有的内容会保持简中，不会变成空白。
- 界面文案（按钮、菜单等）使用随模组分发的 FairyGUI 文案 XML。
- 英 / 日 / 繁的字体沿用游戏自带的字体资源；切换前会先预检，加载不到时回退简中字体并记录日志，避免登录界面卡死。
- 语音语言是「设置 → 音量 → 角色语音」里的独立选项，不受这里影响。

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关。关闭后保持简中，并停止接管语言选项。 |
| `language` | `zh` | 当前语言：`zh` / `en` / `ja` / `tc`。游戏内切换时会自动更新。 |

## 数据包

`data/en.pack`、`data/ja.pack`、`data/tc.pack` 与同名 `.xml` 由维护者工具从国际服客户端生成：

```powershell
python mods\LanguageUnlockMod\tools\build-language-data.py
```

需要本机装有国际服客户端（`8vJXnINT`）和 UnityPy。脚本只读取客户端缓存里的文本资源，不修改游戏文件。
