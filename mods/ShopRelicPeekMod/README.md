# 商店与筹码看板（ShopRelicPeekMod）

在游戏右上侧独立展示当局玩家进入卡牌商店遇到的货架卡牌，以及选择筹码时的候选筹码、刷新历史与最终选定结果。支持按键一键清空。

## 功能

- **双看板独立分置与自动避让**：商店看板与筹码看板采用独立面板渲染，分别配置位置与尺寸，互不遮挡干扰：
  - **商店看板**：默认位于右上角（Y=70）。
  - **筹码看板**：默认位于商店看板下方（Y=320）；若商店看板正在显示，筹码面板会自动检测商店下沿并自动下移避让（间距 12px），绝不遮挡商店内容。
- **一键快捷清空**：默认按下 **`T`** 键可立刻一键清空屏幕上的商店与筹码看板内容，保持画面清爽（在输入框聊天打字时自动屏蔽防误触，键位支持在配置中任意更改）。
- **卡牌商店透视**：当玩家走进卡牌商店（PVE 商店、PVP 商店、商人买卡）时，实时显示其货架上出现的卡牌；已购买的卡牌标记为 `(已售)`。离开商店后保持显示一定时长（默认 20 秒），方便确认队友或对手遇到的手牌。
- **筹码候选与刷新历史**：当玩家开始选筹码时，显示当前的候选筹码。若玩家点击刷新，看板会保留之前的候选筹码历史，并更新当前最新候选。
- **选定结果保持**：玩家选定筹码后，不再瞬间消失，而是高亮展示最终选定的筹码并保持显示一定时长（默认 20 秒），供所有玩家从容查看选牌结果与刷新记录。
- **楼层排版与专属配色**：看板中的玩家名字按照游戏座位顺序（一楼至四楼）排列，并采用官方专属配色：
  - 一楼：红色（`#FF4646`）
  - 二楼：绿色（`#94FF46`）
  - 三楼：蓝色（`#4386F4`）
  - 四楼：黄色（`#FFB346`）
- **筹码品质着色**：候选筹码名称支持按品质高亮显示（普通为蓝色、稀有为紫色、传说为橙色）。
- **动态显隐**：仅在有活跃内容时显示对应看板；无动态事件时自动隐藏，不遮挡游戏画面与鼠标点击。

## 配置项

配置文件位于 `AstralParty_ModLoader/mods/ShopRelicPeekMod/config.json`，可在 Toys 玩具箱设置中直接调整：

| 键名 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | boolean | `true` | 总开关：是否启用商店与筹码看板 |
| `clearKey` | string | `"T"` | 一键清空看板内容的快捷键（按键名称，如 T、F1、None） |
| `fontSize` | int | `18` | 文本字号（范围 12–36） |
| `showFloorTag` | boolean | `true` | 玩家名字前是否显示【一楼】至【四楼】标签 |
| `showShopCards` | boolean | `true` | 是否启用商店独立看板 |
| `shopPanelWidth` | float | `340.0` | 商店看板宽度（像素，范围 200–600） |
| `shopOffsetX` | float | `20.0` | 商店看板距离屏幕右边缘的水平偏移量（像素） |
| `shopOffsetY` | float | `70.0` | 商店看板距离屏幕顶部的垂直偏移量（像素） |
| `shopDisplayDurationSeconds` | int | `20` | 离开商店后卡牌保持显示的秒数 |
| `showRelicCandidates` | boolean | `true` | 是否启用筹码独立看板 |
| `relicPanelWidth` | float | `340.0` | 筹码看板宽度（像素，范围 200–600） |
| `relicOffsetX` | float | `20.0` | 筹码看板距离屏幕右边缘的水平偏移量（像素） |
| `relicOffsetY` | float | `320.0` | 筹码看板距离屏幕顶部的垂直偏移量（像素，自动避让商店） |
| `relicDisplayDurationSeconds` | int | `20` | 选定筹码后历史与选定结果保持显示的秒数 |
| `colorRelicByQuality` | boolean | `true` | 筹码名称是否按品质（普通蓝、稀有紫、传说橙）着色 |
