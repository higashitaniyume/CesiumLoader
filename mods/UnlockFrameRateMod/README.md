# 帧率解锁（UnlockFrameRateMod）

在游戏「设置 → 屏幕 → 帧率」下拉框里追加 **144、165、240、360、不限帧** 五个选项，选中后由游戏自己应用，和原生 30/60/90/120 一样保存在游戏设置里。

## 功能

- 原生帧率列表保持原样，新选项追加在末尾。
- 选中「不限帧」时游戏会把目标帧率设为不限；144/165/240/360 则作为上限。
- 游戏在启动、重新登录或切换语言时会重建配置表，本模组会自动把选项补回去。
- 关闭本模组（`enabled=false`）即移除额外选项，恢复原版列表。

## 使用

打开游戏「设置 → 屏幕 → 帧率」，选择需要的帧率即可。

「不限帧」需要先关闭游戏内的「垂直同步」：勾选垂直同步时，游戏会把帧率下拉框置灰（垂直同步本身会按显示器刷新率封顶）。

## 说明

- 选择和原生选项一样保存在本地，下次启动继续生效。启动后最多约 1 秒内会应用所选值。
- 不限帧的实际上限由显示器、显卡驱动与窗口模式共同决定：无边框窗口受 Windows 桌面合成限制，驱动控制面板里强制开启的垂直同步也无法被游戏覆盖。
- 帧率越高，显卡占用与发热越大；笔记本或长时间挂机建议选择 144/240 之类的上限。
- 只影响画面帧率；对局内容与结果仍由服务器判定。
- 需要 CesiumLoader 2.8.10 或更新版本（随加载器包提供）。

## 配置

`AstralParty_ModLoader/mods/UnlockFrameRateMod/config.json`：

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关；关闭后移除额外帧率选项 |

首次运行时自动生成带简中、繁中、英文、日文说明的配置文件。1.0 版本的 `frameRate`、`toggleKey` 等旧键已不再使用，会在启动时自动清理。
