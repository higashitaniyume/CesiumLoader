# PVE 面板（PvePanelMod）

PVE 对局里的合并信息面板：左侧信息栏、右侧情报栏、战斗面板、手牌抽屉。把「商店与筹码看板」「PVE 波次预告」「手牌查看」和「战斗胜率助手」的战斗读数收进同一套界面，只在 PVE 对局里出现。只读，不发送对局操作。

## 功能

- **左侧信息栏**（贴屏幕左边，可收起）：每个玩家一行。
  - 头像直接借官方左栏的图（皮肤自动对上），底板是楼层色网点（一楼红、二楼绿、三楼蓝、四楼黄）。
  - 血量（三成以下变红）、星币、手牌数；三颗星 = 星级（`Property.level`）。
  - 技能图标：就绪时亮，冷却中变灰、右下角写还差几回合（差 1 回合时变黄）。
  - buff 只放图标（最多 4 个，层数写在右下角），只显示游戏自己也显示的 buff（`IsShow`），筹码的内部计数不显示。
  - 被击倒时头像变灰；离线时 buff 栏前加电脑标记（只看实时的 `Player.OffLine` / `Property.Online`）。
  - 展开时隐藏官方左栏，收起时恢复。
- **右侧情报栏**（贴屏幕右边）：
  - 第一排：下一波怪物、下一次轮次奖励「N回合后 / 下回合！」。刷怪和轮次奖励都在回合开头结算，奖励在第 3、6、9… 回合。
  - 波次表：接下来最多 3 波，怪物头像 × 数量、刷怪格子编号或「随机」（波次数据沿用「PVE 波次预告」的算法）。
  - 一至四楼各一行：这个人最近一次的商店（卡面）或筹码（品质底图 + 图标）。进行中有绿点；结束后不消失：买了的卡 / 选中的筹码盖深色 + ✓，没选的筹码连底色变黑白。
- **战斗面板**（挂在左栏下面，战斗时出现）：该防御 / 该闪避、两种选择的**挺住（存活）概率**、击杀概率和预计伤害。计算全部由「战斗胜率助手」完成，见下文。
- **手牌抽屉**（左栏右边的粉色把手）：每行和左栏玩家对齐，同牌合并显示「×N」，超过 7 种叠起来；左栏收起时也能拉出，每行前面加楼层色条。
  - 自己和 Bot 的手牌直接读本地，不联网。
  - 真人队友的手牌被游戏遮住，抽屉打开、拿到本局观战码时通过第三方观战服务查询（`HandService` 默认开，可在配置里关掉）；全 Bot 局也照查，但本地能读到的牌优先用本地数据。
- **悬停小字**：buff、商店卡面、筹码、波次怪物头像，鼠标停 0.5 秒显示名字和说明（说明里的占位符和内嵌小图标都按游戏的格式处理）。
- 面板整体不挡鼠标，只有把手和缩放按钮接点击。

## 使用

1. 在玩具页启用「PVE 面板」，或直接把 `config.json` 里的 `Enabled` 改成 `true`（改完立即生效，不用重启游戏）。建议同时关掉它替代的「商店与筹码看板」「PVE 波次预告」「手牌查看」，免得同样的信息画两份。
2. 进入 PVE 对局即显示。
3. 左栏右边：`‹` 收起 / 展开左栏，粉色把手拉出 / 收回手牌抽屉。左栏底部 `－` `＋` 调整整体大小。
4. 快捷键（聊天打字时、游戏不在前台时不响应）：`F3` 左栏，`F4` 手牌，`F5` 隐藏 / 显示右栏（会记住）。

## 配置

| 字段 | 说明 | 默认 |
|---|---|---|
| `Enabled` | 是否显示面板。改成 `true` 立即生效（不用重启游戏） | `false` |
| `UiScale` | 面板整体缩放，0.8–1.5（左栏底部的 `－` `＋` 也能调，自动记下） | `1.0` |
| `LeftToggleKey` | 收起 / 展开左栏的快捷键，`None` = 不用 | `F3` |
| `HandToggleKey` | 拉出 / 收回手牌抽屉的快捷键 | `F4` |
| `RightToggleKey` | 隐藏 / 显示右栏的快捷键 | `F5` |
| `RightPanelHidden` | 右栏是否隐藏（按快捷键切换时自动记下） | `false` |
| `LeftPanelCollapsed` | 左栏是否收起（按快捷键或点把手切换时自动记下） | `false` |
| `HandService` | 抽屉打开时查询手牌：拿到本局观战码就发给第三方观战服务（全 Bot 局也查） | `true` |
| `HandServiceUrl` | 第三方观战服务地址 | `https://aspac.hiynet.com/` |

## 与「战斗胜率助手」的配合

战斗读数不在本 mod 里重算。`CombatOddsMod` 把每次算好的结果放进公开的 `BattleOddsFeed`，本 mod 按名字反射读取（不声明硬依赖：没装战斗胜率助手时面板其余部分照常工作）。面板显示战斗读数时会持续调用 `BattleOddsFeed.ClaimDisplay()`，战斗胜率助手在这期间不再画自己 FightWindow 里的读数框；面板收起或关掉后 3 秒内自动恢复。

## 代码来源

- `Hands/QueryController.cs`、`ServiceAddress.cs`、`UnityHandRequest.cs` 基于 [hpenguins/HandViewerMod](https://github.com/hpenguins/HandViewerMod)（AGPL-3.0，作者 hpenguins）改写。改动：成功后至少隔 5 秒再查（原 1.5 秒），手牌变动后攒 1.5 秒再查（原 0.6 秒），重新展开时遵守服务器的 `Retry-After`（原版会清掉等待，是「连接失败」= HTTP 429 的来源之一）。对应测试也来自原仓库，改动处有注释。
- `WaveModels.cs`、`WaveScheduleCore.cs`、`WaveSchedule.cs` 复制自本仓库的 `PveWaveForecastMod`，只改了命名空间。
- `data/relicbase_*.png`（筹码品质底图）来自游戏资源 `UT_RelicBase_*`：游戏里按这个名字加载不到，所以随 mod 附带。其余小图标为本 mod 自绘，同样放在 `data/` 随包分发。

## 说明

- 字段都在游戏里实测过（星级 `Property.level`、技能 CD `BattlePlayerData.SkillCD`、回合 `RoomInfo.Round` 等）。`Hero.Lv`、`Hero.Hp`、`Hero.OfflineType` 是快照或历史记录，不能当实时状态用。
- 「离线」只看 `Player.OffLine` / `Property.Online`；挂机和掉线走的是同一套在线状态字段。
