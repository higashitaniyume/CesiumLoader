# 回合置前 TurnFocusMod 1.6.0

轮到自己需要操作、匹配成功、收到房间邀请，或开房后有人喊“准备”时，把游戏窗口切换到前台；配置了提示音时同时播放。游戏窗口已经在前台时不会反复抢焦点。

**默认不播放提示音**：只有自己指定 WAV 文件后才会出声。

## 触发时机

- 自己的回合开始
- 选择筹码（筹码三选一）
- 战斗询问（是否开战）
- 战斗出牌（攻击或防御用牌）
- 攻击骰
- 防御选择（闪避/硬抗）
- 匹配成功（显示匹配成功结果时）
- 收到房间邀请（右上角出现邀请按钮时）
- 匹配成功开房后，房间里其他玩家发送“准备”之类的快捷消息

回合相关触发判断使用游戏的行动开始通知与原始动作流，只处理属于自己（`PlayerId` 为自己）的动作，与游戏原版显示操作窗口的时机一致。匹配成功通知到达时游戏刚创建房间，因此只排除回放和观战，不依赖房间状态。房间邀请只在游戏会显示右上角邀请按钮时触发，也就是不在房间里、也不在组队里的时候；自己已经在房间或队伍中时按钮本就不出现，不会切窗。房间快捷消息只处理等待阶段（选人、准备）里别人发的消息，自己发送的消息和战斗中的快捷消息不触发。回放和观战不触发。

## 行为

- 同一动作只请求一次；多个动作连续出现时按冷却时间合并请求。
- 游戏窗口最小化时先恢复，再切换到前台。
- 如果系统前台锁定阻止切换（例如前台是全屏程序或提权窗口），加载器会闪烁任务栏提醒，不会反复尝试；提示音照常播放。
- 窗口已经在前台时不改变窗口状态；提示音默认也不响，只有 `alwaysPlaySound` 打开时才在每次请求都响一次。
- 提示音与置前同一次请求执行，实际延迟取决于加载器轮询（约 0.1 秒）。

## 提示音

- **默认静音**，只有把 `soundFile` 指定为一个 WAV 文件才会播放。
- **默认只在窗口不在前台时播放**（这时置前才是真正需要的提醒）；把 `alwaysPlaySound` 设为 `true` 后，每次请求都会响一次，不管窗口在不在前台。
- 随包提供一个示例音 `sounds/your-turn.wav`（0.55 秒双音），把 `soundFile` 改成这个路径即可启用。
- 只支持 **WAV**：建议 16-bit PCM、44.1 kHz、单声道、2 秒以内，文件不超过 16 MB。
- 换成自己的音频：把 WAV 放进 `AstralParty_ModLoader/mods/TurnFocusMod/sounds/` 后 `soundFile` 写相对路径；也可以直接写绝对路径（支持中文路径）。
- 提示音由加载器直接播放，不经过游戏音频：游戏内音量/静音不影响它；想单独调小，用 Windows 音量合成器里本游戏的音量。
- 文件缺失、不是 WAV 或超过 16 MB 时只写日志，置前不受影响。连续触发时新的提示音会打断上一段，不会叠音。

## 安装

需要 CesiumLoader 2.7.2 或更高版本，并需要加载器提供窗口置前通道。将安装包中的 TurnFocusMod 文件夹解压到游戏 `AstralParty_ModLoader/mods/` 下，重启游戏。随加载器包分发时无需额外安装。

## 配置

修改模组目录的 `config.json`，保存后约 1 秒内自动热重载（无需重启游戏）：

- `enabled`：开关，默认 `true`。
- `cooldownSeconds`：相邻两次置前请求之间的最小间隔，默认 `1`，范围 0–60。窗口已在前台时请求本身不改变窗口，因此通常无需调大。
- `focusOnMatchSuccess`：匹配成功时是否置前，默认 `true`。
- `focusOnRoomChat`：匹配成功开房后，其他玩家发送“准备”等快捷消息时是否置前，默认 `true`。
- `focusOnRoomInvite`：收到房间邀请（右上角出现邀请按钮）时是否置前，默认 `true`。
- `soundEnabled`：是否启用提示音，默认 `true`。关掉后即使 `soundFile` 有值也不播放。
- `soundFile`：提示音文件（WAV）。**默认空字符串，即只置前、不出声**；相对路径按模组目录解析，也可写绝对路径。
- `alwaysPlaySound`：提示音是否无视前台状态，默认 `false`。
  - `false`：只在游戏窗口**不在前台**时播放（置前真正生效时）；
  - `true`：每次请求都播放一次，窗口已经在前台也响。

## 说明

热更程序集无法直接调用 Windows 窗口 API，也无法直接播放音频；置前和提示音都由加载器的窗口控制文件通道执行。加载器配置中的 `windowControlEnabled` 设为 `false` 时该通道关闭，本模组会在日志中提示不可用，其余功能不受影响。
