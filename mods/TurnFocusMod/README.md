# 回合置前 TurnFocusMod 1.3.0

轮到自己需要操作、匹配成功，或开房后有人喊“准备”时，把游戏窗口切换到前台。游戏窗口已经在前台时不做任何操作，不会反复抢焦点。

## 触发时机

- 自己的回合开始
- 选择筹码（筹码三选一）
- 战斗询问（是否开战）
- 战斗出牌（攻击或防御用牌）
- 攻击骰
- 防御选择（闪避/硬抗）
- 匹配成功（显示匹配成功结果时）
- 匹配成功开房后，房间里其他玩家发送“准备”之类的快捷消息

回合相关触发判断使用游戏的行动开始通知与原始动作流，只处理属于自己（`PlayerId` 为自己）的动作，与游戏原版显示操作窗口的时机一致。匹配成功通知到达时游戏刚创建房间，因此只排除回放和观战，不依赖房间状态。房间快捷消息只处理等待阶段（选人、准备）里别人发的消息，自己发送的消息和战斗中的快捷消息不触发。回放和观战不触发。

## 行为

- 同一动作只请求一次；多个动作连续出现时按冷却时间合并请求。
- 游戏窗口最小化时先恢复，再切换到前台。
- 如果系统前台锁定阻止切换（例如前台是全屏程序或提权窗口），加载器会闪烁任务栏提醒，不会反复尝试。
- 窗口已经在前台时请求被静默忽略，不改变窗口状态。

## 安装

需要 CesiumLoader SDK 2.6.0 或更高版本，并需要加载器提供窗口置前通道。将安装包中的 TurnFocusMod 文件夹解压到游戏 `AstralParty_ModLoader/mods/` 下，重启游戏。随加载器包分发时无需额外安装。

## 配置

修改模组目录的 `config.json`，保存后自动热重载：

- `enabled`：开关，默认 `true`。
- `cooldownSeconds`：相邻两次置前请求之间的最小间隔，默认 `1`，范围 0–60。窗口已在前台时请求本身不改变窗口，因此通常无需调大。
- `focusOnMatchSuccess`：匹配成功时是否置前，默认 `true`。
- `focusOnRoomChat`：匹配成功开房后，其他玩家发送“准备”等快捷消息时是否置前，默认 `true`。

## 说明

热更程序集无法直接调用 Windows 窗口 API，置前由加载器的窗口控制文件通道执行。加载器配置中的 `windowControlEnabled` 设为 `false` 时该通道关闭，本模组会在日志中提示不可用，其余功能不受影响。
