# CesiumLoader 3.0.0

## 模组启动门（就绪即启动）

将原先模组启动时的固定 30 秒等待调整为启动门就绪判定，大幅加快模组初始化速度：

- 游戏进入可玩场景（主界面、战斗、单人等）且主界面或 UI 面板打开后即判定为就绪，稳定 1 秒后立刻初始化全部模组，不再需要盲等 30 秒。
- 模组原有的 `delayMs`（默认 30 秒）现在作为等待上限兜底；若因特殊原因未触发就绪判定，到达上限后仍会正常触发初始化。
- 探测过程全程采用只读检查，不会触发单例提早构造。
- 环境变量选项：若需要恢复旧版的固定等待行为，可设置 `CESIUM_MOD_BOOT_GATE=0`。

## 战斗胜率（CombatOddsMod）性能优化与生命周期管理

- 优化战斗胜率与攻防加成面板的计算路径，减少每帧与每回合的堆内存分配。
- 规范模组生命周期监听清理，在战斗结束与场景切换时集中释放事件与状态缓存。

## 命令行工具（apcsm）支持通过 NuGet 安装

CesiumLoader 脚手架与打包工具已发布至 NuGet（包名 `apcsm`），可作为 .NET 全局工具直接安装与升级：

```shell
dotnet tool install -g apcsm
dotnet tool update -g apcsm
```

支持快速创建新模组项目（`apcsm new`）、编译（`apcsm build`）与打包分发（`apcsm package`）。
