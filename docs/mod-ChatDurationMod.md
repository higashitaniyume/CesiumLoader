# 消息停留时间 ChatDurationMod

战斗界面的快捷消息与表情由游戏自己的消息列表显示，原版只停留几秒。开启变速后，这份计时也会跟着加快，消息会在更短的真实时间里消失。

本模组把消息列表的隐藏时机改为按真实时间计算，默认 15 秒，可配置。动画、战斗、回合与其他界面不受影响。

## 行为

- 战斗消息列表中的快捷消息与表情进入右侧消息列表后，按真实时间停留（队友发送的与本地发送的都包括）。
- 达到配置时长后，条目从屏幕上收起；列表容量已满时，最早的消息仍会先被挤出。
- 变速倍率在显示期间变化也不会缩短停留时间。
- 关闭模组或 `enabled=false` 后恢复游戏原版计时。

## 配置

配置文件：`AstralParty_ModLoader\mods\ChatDurationMod\config.json`。首次运行自动生成；保存后约 1 秒生效。

```json
{
  "enabled": true,
  "durationSeconds": 15
}
```

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关；`false` 时恢复游戏原版停留时长 |
| `durationSeconds` | `15` | 停留秒数（真实时间），范围 1–300；非正数按 15 处理，超过 300 按 300 处理 |

也可以在 Toys 的「模组 → 消息停留时间 → 配置」中修改。

## 说明

- 只操作游戏自己的消息列表：不创建新界面、不发送消息、不修改对局数据。
- 消息列表本身的容量限制仍然有效；连续大量消息时，最早的一条仍可能提前离开。
- 与快捷短语扩展、隐藏 HUD 等界面类模组共存；隐藏 HUD 时消息列表会随父界面一起隐藏。
