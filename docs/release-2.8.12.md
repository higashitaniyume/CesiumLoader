# CesiumLoader 2.8.12

- 新增内置模组「消息停留时间」：战斗消息列表里的快捷消息与表情按真实时间停留，默认 15 秒，可在 `mods\ChatDurationMod\config.json` 调整（1–300 秒）。变速不会缩短停留时间，关闭模组即恢复游戏原版计时。
- 自由相机：新增左右方向键绕地图旋转，观察点留在画面中心，俯角不变；旋转时可改键与调整速度，并抵掉游戏自身的方向键平移。
- 回合置前：收到房间邀请时也把游戏窗口切换到前台。
- 战斗胜率助手：预计伤害改为取伤害分布的众数，无唯一众数时取中位数并四舍五入。
- 加载器 / SDK / CLI 版本统一到 2.8.12。

更新后重启游戏生效，已有模组配置保留。
