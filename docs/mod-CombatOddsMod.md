# 战斗胜率助手（CombatOddsMod）

在打怪与玩家战斗的投牌界面实时显示防御、闪避的被击倒概率，以及攻击方的预计伤害与击杀概率。预计伤害取伤害分布的众数；没有唯一众数（并列最高或各值等概率）时取中位数，落在两个整数之间时四舍五入，因此不会出现小数点。每次投牌、攻防数值变化后刷新，并以颜色标出防御或闪避建议。

## HUD 显示

- 左侧所有玩家的头像区域、昵称上方显示各自的主动技能冷却，例如 `CD 0/3`。数值全部来自服务器：每当有角色出牌或释放技能，就查询一次所有人的当前冷却并刷新显示。分母取该玩家最近一次释放时实际施加的冷却上限（强化、天赋与遗物会改变它），尚未释放过时用配表上限。就绪为绿色，冷却中为黄色，每 0.1 秒刷新一次显示。
- 左侧每个玩家的技能 CD 文本右侧显示剩余手牌数，图标使用游戏自己的卡牌图标：优先取游戏手牌状态文字里内联的图标，取不到时使用公共 UI 的 `Com_Icon_Card`，两者都不可用时只显示数字。数字在摸牌、出牌、换牌与净化后随实时数据刷新（每 0.1 秒读取一次）；自己以本机手牌列表为准，其他玩家用手牌计数。0 张时数字显示为暖色。
- 棋盘上怪物的名字/血量信息条右侧显示其主动技能冷却，例如 `CD 2/3`，白色字黑描边、字号比名字小。默认只显示 BOSS 与配表里真正带主动技能的怪物；普通/精英怪的战斗技能多数就是普通攻击，不计入 CD。数值在怪物释放主动技能时取服务器下发的本次冷却，之后按轮次递减；没有主动技能、配表没有冷却或怪物已死亡时不显示。
- 自己使用梅加斯时，右下角发动技能按钮上方显示轨道轰炸的理论伤害，例如 `梅加斯 理论伤害 32` / `8张(费14) = 4炮 * 8`。手牌张数、费用、开炮次数、单炮伤害与总伤害分别用不同颜色显示。开炮次数为手牌张数除以 2 向下取整，单炮伤害为 `3 + 战斗牌总费用 ÷ 3` 向上取整，理论伤害为两者相乘。手牌或费用变化后随实时数据刷新；不足 2 张时显示无法开炮。回放中同样显示，数据取当前观看玩家的手牌。
- 左下角攻击力旁显示筹码带来的最终攻击力，悬停可查看基础攻击与各项加成。
- 移速加成默认关闭，可在配置里开启：开启后自己角色卡上（「查看筹码」按钮正上方）与棋盘上每名玩家头顶的攻防标签都会带上移速加成，例如 `移速+2`、`攻 6  防 4  速 +2`。预测会把身上所有已知的移速来源加起来：全部已知会加/减移速的 Buff（筹码常驻如速度轮滑 `+1/+2/+4`、梦想号模型 `+2`、永动机 `+2`，以及技能与道具 Buff，含 `下次移动速度±N` 这类一次性效果）、服务器主动推送的临时加减速，以及按层数/条件计算的条目（例如糖糖开大的移速等于她的层数 Buff 层数、思维飞艇 9 层 `+2`、能量回收层数 >5 时 `+1`）。服务器每次移动时顺带下发的各 Buff 实际贡献会覆盖本地表里的数值；客户端读不到来源的常驻加成（建筑效果、隐藏被动等）会自动校准：连续两次投骰的「实际 − 预测」一致时，把该差额并入之后的预测。观战或回放显示当前查看的那名玩家的值；PVP 中没有「查看筹码」按钮，角色卡读数改放防御数字右侧。字号与位置可在配置里调整。
- 棋盘角色头顶显示实时攻击、防御与生命详情，标签每帧跟随相机。
- 防守方是摩西时（自己、队友或观战对象），战斗面板会多一行显示【精密技巧】层数与闪避骰范围，例如 `🔫 精密技巧×2 → 闪避骰 3~6`；0 层时显示 `🔫 精密技巧×0（无闪避加成）`。攻击方骰点不高于层数时，结论显示 `💨 必闪`，闪避概率也按抬高后的骰面重新计算。
- 战斗窗口显示概率与建议；游戏通知提供相应读数。控制台日志默认不打印每次读数（需要排障时打开 `LogBattleOdds`）。

## 配置

配置位于 `AstralParty_ModLoader/mods/CombatOddsMod/config.json`，可在 AstralParty.Toys 的模组配置页面编辑。显示与数值类配置保存后约 1 秒内自动热重载（CesiumLoader 2.6.0 及以上）；`Enabled` 总开关仍需重启游戏。初始化会补齐缺少的配置项，保留已有设置；保存失败会记录警告。

## 概率口径

攻击未锁定时，攻击值按 `MinAtk..MaxAtk` 范围内整数加一颗 d6 枚举；防御同理。范围内整数按等概率且与判定骰独立计算。攻击锁定后直接采用最终攻击值，不重复加骰。

攻击方是否已投骰由加载器按战斗事件推导：未投骰时按最坏情况（`MaxAtk` 加判定骰）估算；已投骰时使用服务器锁定的攻击值。投出 0 点是有效结果（例如摩西【破绽】把怪物战斗骰点压到 0），此时闪避必定成功，不会按“尚未投骰”处理。

普通命中基础伤害为 `max(1, 攻击－防御)`，之后应用已登记的易伤、减伤与免疫效果，最终伤害最低为 0。最终伤害达到目标当前生命值时计为击倒。

攻击侧的击杀概率以目标选择防御为条件。闪避按单颗判定骰计算，普通点数需大于攻击判定骰，上限点数需等于上限；闪避失败且伤害足以致死时才计入被击倒概率。建议优先选择被击倒概率较低的防御方式。

预计伤害显示的是伤害分布的众数；并列众数或各值等概率时取中位数，中位数落在两个整数之间时四舍五入。例如伤害可能是 `3、2、1、1、1、1` 时显示 `1`（众数），`4、5、6、7、8、9` 时显示 `7`（中位数 6.5 四舍五入）。

摩西【精密技巧】每层把闪避骰下限抬高 1，闪避骰在 `层数+1..6` 内等概率取值；攻击方骰点不高于层数时必定闪避。该修正只作用于防守方是摩西的战斗，PVP 的摩西没有这个 buff，按普通闪避计算。

概率受范围等概率假设与已登记效果范围限制；其他角色专属判定、保证闪避等特殊效果仍不属于通用模型。

## 怪物 CD 口径

怪物的冷却没有像玩家那样的逐轮服务器推送：释放主动技能时用服务器下发的本次值校准，之后每轮减 1，直到 0；怪物释放其他技能不会改动这条冷却。普通/精英怪的 `PveActiveSkill` 往往只是普通攻击（如玩具恐龙的「杂音攻击」），默认不显示，避免“没开大 CD 也在变”；需要看全部怪物时把 `ShowMonsterCdForAllMonsters` 设为 `true`。全局冷却缩减、Boss 阶段换技能或额外行动可能让显示与实际短暂相差一轮，下一次释放或重连快照会重新校准。没有主动技能或配表冷却为 0 的怪物不显示。

## buff 修正

读取防守方的实时 buff，并将已登记的受伤修正计入预计伤害和击倒概率。攻击属性中已包含的加成不重复计算。地图事件等已由服务器结算的伤害不套用投牌模型。

| buff ID | 名称 | 受伤修正 | 叠层 |
|---|---|---:|:--:|
| 10006 | 标记 | +1 | —（固定，层数只影响持续） |
| 2000801 | 狂暴 | +1 | 每层 |
| 1140101 | 宿命回响 | +1 | — |
| 1140102 | 虚弱印记 | +1 | — |
| 4000401 | 霉运 | +2 | — |
| 3200501 | 易伤 | +2 | — |
| 10671302 | 真凶 | +2 | — |
| 10141101 | 脆弱中枢 | +1 | 条件性，近似取 +1 |
| 4000301 | 好运 | −2 | — |
| 1261101 | 湖沼之王 | −1 | 每层 |
| 5006001 / 10261101 | 逆鳞 | −2 | 每层 |
| 5007002 | 大铜锣 | −1 | — |
| 10531201 | 灰烬 | −1 | 每层 |
| 10551101 | 稳定中枢 | −1 | 每层 |
| 1071101 | 护盾 | 免疫 | — |
| 1071102 | 护盾 | −3 | — |
| 10331101 | 深度改造 | 免疫（层数归零后失效） | — |
| 10591101 | 铁箍宝藏桶 | 每次最多受伤 1 | — |
| 1291202 | 渊蚀印记 | +1 | 每层（只对魔渊触须/赛克斯的伤害） |

按层数生效的修正与免疫只在层数大于 0 时计入：游戏会为部分 buff 保留 0 层图标，图标仍在但效果已经结束（幽魂暗巷科学怪人的【深度改造】被三个人工生命体各削掉 1 层后就是这种状态），此时不再显示免疫或减伤。一次性 buff（护盾等）的层数不是生效条件，仍按当前状态计入。带“每次最多受伤”的目标，预计伤害与击杀率都按上限计算。

精准打击（1221202）只作用于【轨道轰炸】造成的伤害，其他来源不计入。渊蚀印记（1291202）按层数计入：目标每有一层，受到赛克斯（角色 129）与魔渊触须（召唤物 12911/12912，以及它激活时执行的 12903/12904）造成的伤害 +1；战斗面板按攻方角色是否为赛克斯判断，其他来源的伤害不加成，只在明细里提示。凤凰 Boss 地图事件不显示为通用灰烬修正。其他未登记的 buff 不参与计算。

标记的 `+1` 是固定值，层数只表示剩余持续/消耗，不会叠成 `+N`。鹰眼瞄具、忍术飞镖等筹码按各自的“标记层数”规则产生额外伤害，属于筹码效果，不并入 buff 的固定 `+1`。

## 构建与安装

本模组随 CesiumLoader 发布。手动安装时，将同次构建的 DLL 与 PDB 放入 `AstralParty_ModLoader/mods/CombatOddsMod/`，保留已有配置，重启游戏。

在工作区根目录执行：

```powershell
dotnet build modding/msvc/mods/CombatOddsMod/CombatOddsMod.csproj -c Release --nologo
dotnet test modding/msvc/tests/CombatOddsMod.Tests/CombatOddsMod.Tests.csproj -c Release --nologo
```
