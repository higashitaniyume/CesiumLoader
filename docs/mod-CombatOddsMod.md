# 战斗胜率助手（CombatOddsMod）

在打怪与玩家战斗的投牌界面实时显示防御、闪避的期望受伤与被击倒概率，以及攻击方的期望伤害与击杀概率。每次投牌、攻防数值变化后刷新，并以颜色标出防御或闪避建议。

## HUD 显示

- 左侧所有玩家的头像区域、昵称上方显示各自的主动技能冷却，例如 `CD 0/3`。数值全部来自服务器：每当有角色出牌或释放技能，就查询一次所有人的当前冷却并刷新显示。分母取该玩家最近一次释放时实际施加的冷却上限（强化、天赋与遗物会改变它），尚未释放过时用配表上限。就绪为绿色，冷却中为黄色，每 0.1 秒刷新一次显示。
- 左下角攻击力旁显示筹码带来的最终攻击力，悬停可查看基础攻击与各项加成。
- 棋盘角色头顶显示实时攻击、防御与生命详情，标签每帧跟随相机。
- 战斗窗口显示概率与建议；游戏通知提供相应读数。控制台日志默认不打印每次读数（需要排障时打开 `LogBattleOdds`）。

## 配置

配置位于 `AstralParty_ModLoader/mods/CombatOddsMod/config.json`，可在 AstralParty.Toys 的模组配置页面编辑。显示与数值类配置保存后约 1 秒内自动热重载（CesiumLoader 2.6.0 及以上）；`Enabled` 总开关仍需重启游戏。初始化会补齐缺少的配置项，保留已有设置；保存失败会记录警告。

| 键 | 默认值 | 说明 |
|---|---|---|
| `Enabled` | `true` | 总开关 |
| `ShowForOthers` | `true` | 显示其他玩家战斗的概率与建议 |
| `PopupNotification` | `true` | 显示游戏内通知 |
| `NotificationTtl` | `8` | 通知持续秒数 |
| `DodgeKeepsBaseDefense` | `false` | 闪避失败时是否保留基础防御减伤 |
| `ColorHighlight` | `true` | 高亮结论与关键数字 |
| `ShowBuffBreakdown` | `true` | 显示并计入受伤修正 buff 明细 |
| `InGameOverlay` | `true` | 显示战斗窗口概率面板 |
| `OverlayFontScale` | `1.0` | 概率面板字号缩放 |
| `OverlayAnchor` | `left-center` | 概率面板锚点，支持 `top-left`、`top-center`、`top-right`、`right-center` |
| `OverlayOffsetX` | `0` | 水平偏移，正数向右 |
| `OverlayOffsetY` | `0` | 垂直偏移，正数向下 |
| `ShowRelicAtkBonus` | `true` | 显示 HUD 筹码攻击加成 |
| `ShowBoardPlayerAttrs` | `true` | 显示棋盘角色头顶属性 |
| `LogAtkBonusDetail` | `true` | 记录攻击力加成明细 |
| `LogBattleOdds` | `false` | 把每次战斗读数（多行框）写进加载器日志 |
| `ShowSkillCooldown` | `true` | 显示左侧所有玩家的技能 CD；关闭后全部隐藏 |
| `LogCdDetail` | `false` | 把技能冷却的查询与显示值写入日志，便于排查显示问题 |

## 概率口径

攻击未锁定时，攻击值按 `MinAtk..MaxAtk` 范围内整数加一颗 d6 枚举；防御同理。范围内整数按等概率且与判定骰独立计算。攻击锁定后直接采用最终攻击值，不重复加骰。

普通命中基础伤害为 `max(1, 攻击－防御)`，之后应用已登记的易伤、减伤与免疫效果，最终伤害最低为 0。最终伤害达到目标当前生命值时计为击倒。

攻击侧的击杀概率以目标选择防御为条件。闪避按单颗判定骰计算，普通点数需大于攻击判定骰，上限点数需等于上限；闪避失败且伤害足以致死时才计入被击倒概率。建议优先选择被击倒概率较低的防御方式。

概率受范围等概率假设与已登记效果范围限制；角色专属判定、保证闪避等特殊效果不属于通用模型。

## buff 修正

读取防守方的实时 buff，并将已登记的受伤修正计入期望伤害和击倒概率。攻击属性中已包含的加成不重复计算。地图事件等已由服务器结算的伤害不套用投牌模型。

| buff ID | 名称 | 受伤修正 | 叠层 |
|---|---|---:|:--:|
| 10006 | 标记 | +1 | 每层 |
| 2000801 | 狂暴 | +1 | 每层 |
| 1140101 | 宿命回响 | +1 | — |
| 1140102 | 虚弱印记 | +1 | — |
| 4000401 | 霉运 | +2 | — |
| 3200501 | 易伤 | +2 | — |
| 10671302 | 真凶 | +2 | — |
| 10141101 | 脆弱中枢 | +1 | 条件性，近似取 +1 |
| 4000301 | 好运 | −2 | — |
| 1261101 | 湖沼之王 | −1 | 每层 |
| 5006001 / 10261101 | 逆鳞 | −2 | 每层 |
| 5007002 | 大铜锣 | −1 | — |
| 10531201 | 灰烬 | −1 | 每层 |
| 10551101 | 稳定中枢 | −1 | 每层 |
| 1071101 | 护盾 | 免疫 | — |
| 1071102 | 护盾 | −3 | — |
| 10331101 | 深度改造 | 免疫（层数归零后失效） | — |
| 10591101 | 铁箍宝藏桶 | 每次最多受伤 1 | — |

按层数生效的修正与免疫只在层数大于 0 时计入：游戏会为部分 buff 保留 0 层图标，图标仍在但效果已经结束（幽魂暗巷科学怪人的【深度改造】被三个人工生命体各削掉 1 层后就是这种状态），此时不再显示免疫或减伤。一次性 buff（护盾等）的层数不是生效条件，仍按当前状态计入。带“每次最多受伤”的目标，期望伤害与击杀率都按上限计算。

精准打击（1221202）和渊蚀印记（1291202）仅作用于特定伤害类型，不计入普通投牌伤害。凤凰 Boss 地图事件不显示为通用灰烬修正。其他未登记的 buff 不参与计算。

## 构建与安装

本模组随 CesiumLoader 发布。手动安装时，将同次构建的 DLL 与 PDB 放入 `AstralParty_ModLoader/mods/CombatOddsMod/`，保留已有配置，重启游戏。

在工作区根目录执行：

```powershell
dotnet build modding/msvc/mods/CombatOddsMod/CombatOddsMod.csproj -c Release --nologo
dotnet test modding/msvc/tests/CombatOddsMod.Tests/CombatOddsMod.Tests.csproj -c Release --nologo
```
