# CesiumLoader 2.9.2

## 新内置模组：PVE 波次预告

在 PVE 合作挑战中把「任务波次」的刷新回合、波次标题和怪物名单画到地图上。

- 覆盖全部 PVE 地图与难度：82007 / 82008 / 82010 / 82012 / 82013 / 82014 / 82015 / 82016 / 82017。
- 按回合显示波次标题与刷新内容，例如「第 3 回合：孩子王嘎呜登场，刷新 1 个采集小熊，1 个闹钟猫头鹰」。
- 有精确地块时，按地块显示分配到的那只怪，并按类别区分：
  - `首领·孩子王嘎呜`
  - `精英·采集小熊`
  - `普通·闹钟猫头鹰 ×3`
- 配置没有给出精确地块时，只标出该地图的怪物地块并注明「位置随机」，不会把整波名单贴到每个地块。
- 左上角显示本局完整波次列表，当前进度高亮。
- 默认关闭；进入 PVE 后按 `O` 打开或关闭。聊天输入框获得焦点时不会误触。
- 地图标记比岔路地块标记更高，并可在配置里用 `labelLift` 继续调整。

配置项：`enabled`（默认 `false`）、`toggleKey`（默认 `O`）、`fontSize`、`heightOffset`、`labelLift`、`showSchedulePanel`、`showOnlyNextWave`、`showRandomLandHints`、`maxWaves`。

加载器 / SDK / CLI 版本统一到 2.9.2，内置模组同步到 17 个。更新后重启游戏生效，已有模组配置与自定义值保留。
