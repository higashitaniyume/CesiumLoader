# CesiumLoader 3.1.0

## 新增内置模组：星币商店助手（StarCoinShopMod）

- 在主界面商城「星币商店」标题旁添加「一键购买」按钮，按槽位顺序自动购买并领取商品。
- 自带冷却间隔保护（默认 0.5 秒），防止快速点击触发请求并发丢单。
- 模组配置中提供 8 个槽位的独立开关（`buySlot1` 至 `buySlot8`），默认启用 1、2、7、8 号槽位，可根据需求在配置界面灵活开启或关闭。
- 完整支持多语言配置项说明与注释。

## 战斗胜率助手（CombatOddsMod）怪物防守建议修正

- 修正怪物作为防守方时的策略提示：当防守者为怪物时，不再提示「建议防守」或「建议躲避」，保持提示逻辑与战斗实际参与者一致。

## 音频子系统与运行时音效替换

- SDK 接入独立音频子系统，提供更可靠的音频播放、音效截获与运行时资源替换能力。
- 随包内置 AudioSkinMod，支持对游戏内置音效进行无感替换。

---

加载器 / SDK / CLI 版本统一到 3.1.0。更新后重启游戏生效，已有模组配置与自定义值保留。
