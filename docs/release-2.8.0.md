# CesiumLoader 2.8.0

- 新增调试 shell：在控制台窗口里直接输入命令，查看环境、改配置、看日志，不用改文件或重启游戏。
  - 配置键为 `loader.<字段>` 与 `<ModId>.<键>`，`ls` 列出全部可配置项，`get` / `set` 读写单个键。
  - 命令：`help`、`status`、`env`、`paths`、`mods`、`hooks`、`log`、`proc`、`ls`、`get`、`set`、`reload`、`clear`、`detach`、`exit`。
  - 修改配置立即写盘，保留原有注释与格式，原文件备份为 `.bak`；写盘前重新解析校验。
  - 加载器字段按生效时机区分“立即生效 / 只能开启 / 重启后生效”；模组配置由模组自身热重载。
  - 鼠标滚轮可回看控制台日志；按住左键拖选、右键或 `Enter` 复制，开始输入时视口自动回到底部。
- 新增配置项 `shellEnabled`（默认开启），关闭后不再读取控制台输入，日志窗口照常显示。
- 战斗胜率助手 2.3.9：每次战斗读数的多行框默认不再写日志（`LogBattleOdds`，需要排障时打开）；没有 UI 渲染后端时不再把通知文本镜像进日志。
- `set` 支持数值范围与类型校验，例如倍率拒绝低于 1 倍、超时限制 1–3600。
- 控制台窗口始终由传统控制台承载：Windows 默认终端设置只作用于控制台程序启动时创建的控制台，不会接管加载器后续分配的控制台。

更新后重启游戏生效，已有模组配置保留。
