# CesiumLoader 3.1.2

## 新增内置模组：商店与筹码看板（ShopRelicPeekMod）

在游戏画面右上角独立显示商店货架与筹码选择动态：

- **商店货架实时看板**：
  - 当任意玩家进入商店时，实时展示当前货架上的 4 张卡牌（附带星币费用）。
  - 当货架卡牌被购买时，实时标红提示 `(已售)`。
- **筹码选择与刷新追踪**：
  - 当任意玩家进入筹码选择时，实时展示当前轮次的 3 枚候选筹码。
  - 支持追踪多轮刷新历史，保留刷新前的候选记录；选定筹码后高亮展示最终结果并在保留指定时长后自动隐藏。
- **双看板独立排版与动态避让**：
  - 商店信息与筹码信息采用双层独立看板排版，互不遮挡；当两侧高度重叠时自动执行垂直动态避让。
- **一键清空热键**：
  - 默认按 `T` 键可立即清空并隐藏当前所有看板信息，在处于聊天框输入或文本输入聚焦时不响应热键。
- **坐席颜色区分**：
  - 玩家名称与序号按官方一至四楼经典配色（红、绿、蓝、黄）着色，辨识直观。
- **完整多语言配置**：
  - 随包配置带完整多语言注释（简中、繁中、英文、日文），Toys 玩具页可直接捕获修改快捷键与各项显示开关。
