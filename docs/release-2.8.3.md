# CesiumLoader 2.8.3

- 新增内置模组「回合时钟」：变速时你自己的操作倒计时仍按真实时间走 —— 2 倍速下 30 秒的回合窗口依旧是 30 秒真实时间，动画、战斗表演、其他玩家回合与 PVE 怪物回合照常加速。
  - 覆盖掷骰、选方向、商店、事件、筹码、战斗出牌/防御等由你操作的窗口。
  - 其他玩家回合的倒计时显示也按真实时间走，可用 `otherPlayers` 关闭。
  - 只在倍率大于 1.0x 时生效；中途改倍率或关掉变速都不会残留状态。
  - 配置：`enabled`、`otherPlayers`、`dryRun`、`logWindow`、`speedRefreshSeconds`，成员名相关键仅在排障时使用。

更新后重启游戏生效，已有模组配置保留。
