# CesiumLoader 2.9.1

## 回合时钟：选人、结算、房间等待与剧情自动播放

变速会把引擎里的倒计时一起加速，回合时钟现在把这些界面上的倒计时也按真实时间走：

- **选人界面**（选英雄、选皮肤）：到点不再提前自动确认；
- **结算界面**：自动翻页按真实时间走，战报可以看完；
- **房间等待**：等待超时不再提前退出房间，房主也不会提前把房主转给别人；
- **剧情自动播放**：翻页按真实时间走，想让它跟着变速跑可以在配置里关掉。

每处都有独立开关（`heroSelect` / `settlement` / `roomWait` / `storyAuto`，默认开启），旧配置在首次启动时自动补齐这四个开关。动画、战斗表演、其他玩家回合与 PVE 怪物回合仍按你设置的倍率加速。

## 战斗胜率：移动速度加成

- 新增可选显示（默认关闭）：自己角色卡「查看筹码」按钮正上方，以及棋盘上每名玩家头顶的攻防标签里带上移速加成，例如 `移速+2`、`攻 6  防 4  速 +2`。
- 预测会累加已知的移速来源：筹码常驻、技能与道具 Buff（含 `下次移动速度±N` 这类一次性效果）、服务器推送的临时加减速，以及按层数或条件计算的条目。服务器每次移动顺带下发的各 Buff 实际贡献会覆盖本地数值。
- 客户端读不到来源的常驻加成（建筑效果、隐藏被动等）会自动校准：连续两次投骰的「实际 − 预测」一致时，把差额并入之后的预测。
- 观战与回放显示当前查看玩家的数值；PVP 没有「查看筹码」按钮，角色卡读数放在防御数字右侧。
- 配置项：`ShowMoveBonus`（默认 `false`）、`MoveBonusFontSize`、`MoveBonusOffsetX` / `MoveBonusOffsetY`、`LogMoveBonusDetail`。

加载器 / SDK / CLI 版本统一到 2.9.1。更新后重启游戏生效，已有模组配置与自定义值保留。
