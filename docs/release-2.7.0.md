# CesiumLoader 2.7.0

发布日期：2026-10-25

- 启动日志重新排版：控制台按窗口宽度折行，续行缩进对齐正文；中英文与 emoji 按两列宽度计算，调整窗口大小后立即生效。
- 日志里的长路径改为 `<loader>\`、`<game>\`、`%LOCALAPPDATA%\` 简写，绝对根目录只在开头打印一次。
- mod 清单与加载结果合并成一张表（序号 / 名称 / 版本 / 结果 / 耗时），去掉重复的 `[i/n]` 编号；`Assembly.Load` 的重载扫描整个过程只报一次结论。
- 变速与窗口置前两个文件通道各合并为一行；倍率统一显示为 `2.0x`；空行不再写入日志文件。
- 新增环境行：游戏版本、Unity 引擎版本（`UnityPlayer.dll`）、进程号与位数。
- `[hijack]` 标签改为 `[loader]`，并区分标题、成功、失败、警告、禁用与路径的配色。
- 原生层日志文本全部改为英文，包含 Steam 绕过各阶段的诊断输出；控制台或管道不可写时改用其他输出方式，重定向到文件时不再丢内容。
- 加载器、SDK 和 CLI 版本统一为 2.7.0；分发 DLL 与同次构建 PDB 成对更新。

SDK 程序集标识保持 2.5.1.0，已安装的 mod 无需重新编译；2.6.x 的配置与模组布局照常读取。
