# mod：FreeCameraMod（滚轮缩放 + 方向键旋转地图）

> 源码：`mods/FreeCameraMod/ModEntry.cs`。纯 SDK 用户，不使用任何反射或内部 API。
> **2.2.1 起整体重写**：旧版的「F1 开关俯瞰视角 / 滚轮调高度」已经删掉，这一页描述的是新行为。
> **2.4.0 起**新增 `autoFollow`：可以关掉自动跟随。**2.4.1 起**关闭后切换角色不再移动镜头；
> **2.4.2 起**关闭后回合开始、刷怪、演出运镜等游戏自动运镜也不会移动镜头。
> **2.4.3 起**锁定镜头默认不开启（`autoFollow` 默认 `true`），必须手动改成 `false` 才启用。
> **2.4.4 起**开大/战斗演出用的独立 PK 相机也会冻结在开场机位，演出运镜不再移动画面。
> **2.4.5 起**回合开始/刷怪时游戏把主相机临时移到占位位置也不会释放锁定，镜头不会再跟着跑。
> **2.6.0 起**新增**左右方向键旋转地图**：按住 `←`/`→` 让整张棋盘绕当前观察点转，俯角不变。
>
> ⚠️ **锁定镜头功能默认不开启**：`autoFollow` 默认是 `true`（保持游戏自动跟随）。
> 要启用锁定镜头，把 `autoFollow` 改成 `false`；CesiumLoader 2.6.0 起保存后自动热重载，无需重启。

## 1. 它做什么

| 时机 | 行为 |
| --- | --- |
| 进入游戏 / 进入棋盘 | **默认什么都不做**。相机完全是游戏自己的，没有开关、没有自动接管、不改任何相机参数 |
| 滚动鼠标滚轮 | **放大 / 缩小**：相机沿**当前视线方向**前后移动（向前滚 = 拉近），**朝向、俯角、滚转一点不变** |
| 按住 `←` / `→`（可改键） | **旋转地图**：相机绕**当前观察点**（自由相机对象 / 角色）的竖直线环绕，观察点始终留在画面中心，**俯角、滚转、远近都不变** |
| 按 `F1`（可改键） | **恢复原来的视角**：缩放与旋转一起归零，立刻回到游戏自己的机位，并把相机交还游戏 |
| `autoFollow=false`（手动开启） | **锁定当前镜头**：角色走路、切换角色、回合开始、刷怪、开大/战斗演出都不会移动画面；玩家拖拽/按键平移自由相机仍按游戏原样 |

和旧版最本质的区别：旧版是「把相机抬到高处俯视」（视角一定会变），新版是「**同一个视角**只是拉近/拉远」，
旋转则是「**同一个俯角**只是绕着观察点转」—— 画面不会变形、不会变成俯视，只是远近变了 / 地图转了个方向。

`autoFollow` 默认 `true`，即**不开启锁定镜头**，完全保持游戏原来的跟随。
只有手动改成 `false`（开启锁定）后才会：
- 角色（包括骰子移动）走路时镜头**不再跟着走**；
- 游戏切换当前玩家/角色时，镜头**也不会跳到新角色**；
- 回合开始、刷怪、开大/战斗演出等游戏自动运镜**都不会移动画面**
  （演出用的独立 PK 相机会冻结在开场机位）；
- 玩家自己拖拽/按键移动自由相机时，镜头跟着操作走，之后停在新的位置。

这个开关保存后自动热重载；切换 `autoFollow` 会重置并重建镜头锁定，不需要重启游戏（CesiumLoader 2.6.0 及以上）。

## 2. 操作

| 操作 | 作用 |
| --- | --- |
| `←`（`rotateLeftKey`） | 让视点向**左**转（yaw 减小）：相机绕观察点往一边转，地图在画面里往另一边转 |
| `→`（`rotateRightKey`） | 让视点向**右**转（yaw 增大）；即相机的转向和按住鼠标往右看一样 |
| 滚轮向前 | 沿视线**拉近 / 放大**（每格 `zoomStep` 米） |
| 滚轮向后 | 沿视线**拉远 / 缩小**（看得更多） |
| `F1`（`restoreKey`） | 回到游戏原来的视角（缩放与旋转一起归零），相机交还游戏 |
| `F2`（`resetKey`） | 同上（第二个复原键；设成 `None` 可关掉） |

- **没有开关**：不需要先按什么键「进入自由相机」，滚一下或按住方向键就有；
- **方向可以反**：默认 `→` 是「视点向右转」，画面里的地图往左转；如果你想要「`→` = 地图向右转」，
  把 `invertRotate` 改成 `true`（即时热重载）。方向键本身永远按「左/右」读，反转只影响转动的角度符号；
- **点按也转得动**：按一下方向键至少转 `rotateStep` 度（默认 15°），按住则按 `rotateSpeed`（默认 90°/秒）连续转；
- **不需要按 F1 才能退出**：缩放偏移回到原位**且没有旋转**时会自动交还相机；`F1` 是「立刻回到原位」的快捷方式；
- **旋转会保留**：松开方向键后地图停在新方向（mod 每帧把它写回去），直到按 `F1`、切场景或换相机；
- **只「读」输入**：不 Capture 鼠标、不拦截按键。游戏自己的**鼠标拖拽平移 / 键盘平移照常有效**——
  缩放/旋转期间每帧都以「游戏本帧写下的位姿」为基准重算，所以可以一边转地图，一边继续拖；
- **旋转后平移方向会自动换算**：拖动鼠标或按键盘平移时，mod 会把这一帧的位移按当前地图角度转一下，
  所以画面转了多少度、拖拽方向就跟多少度，不会出现「往右拖、地图却斜着走」；
- `F1` 在**没缩放也没旋转**的时候按下是空操作（不弹提示、不改任何东西）。

### 和游戏自己的方向键平移的关系

游戏本来就把 `←`/`→` 当「键盘操作」的 `Horizontal` 轴用来平移自由相机。mod 只读输入、拦不住游戏，
所以默认 `blockPanWhileRotate=true` 会在按住旋转键时，把**自由相机对象**的位置拉回本帧开始前
（只动 `Core.FreeCameraObject`，角色/演出相机不受影响），让左右键**只旋转地图**，不会同时把地图推走。

游戏平移用的是自由相机对象的**世界** forward/right，而画面已经被 mod 转了 `yawDelta` 度。
不处理的话，旋转后拖拽/键盘平移都会歪同样的角度；mod 每帧把这一帧的实际位移绕基准点转
`yawDelta` 度后再写回自由相机对象，所以**旋转后拖拽和键盘平移的方向仍然与画面对应**。
按住旋转键时（`blockPanWhileRotate=true`）这一帧位移会被整个抵掉，只剩旋转。

开着游戏设置里的「键盘操作」时，按下方向键本身仍会让游戏切到自由相机（这是游戏自己的行为，
mod 不改变它）；切换到自由相机之后，旋转就是绕自由相机对象进行。
把 `blockPanWhileRotate` 改成 `false`，就是「旋转的同时地图也会被推开」（方向同样会换算）。

## 3. 配置

配置文件：`AstralParty_ModLoader\mods\FreeCameraMod\config.json`
（**与 mod 的 dll 同目录**；首次运行 / 从旧版升级时会自动生成，并**清掉旧版 v2.x 用过的键**）

```json
{
  "autoFollow": true,
  "zoomStep": 20,
  "zoomInMax": 120,
  "zoomOutMax": 1500,
  "invertWheel": false,
  "smooth": true,
  "smoothTime": 0.12,
  "ensureFarClip": true,
  "requireReadyCamera": true,
  "maxReadyCameraHeight": 500,
  "notify": true,
  "restoreKey": "F1",
  "resetKey": "F2",
  "rotateLeftKey": "LeftArrow",
  "rotateRightKey": "RightArrow",
  "rotateSpeed": 90,
  "rotateStep": 15,
  "invertRotate": false,
  "blockPanWhileRotate": true
}
```

> ⚠️ 配置保存后约 1 秒内自动热重载，不需要重启游戏（CesiumLoader 2.6.0 及以上）。
> JSON 支持 `//` 与 `/* */` 注释。启动时损坏的文件仍会备份为 `config.json.bak` 并使用默认值；
> 运行中热重载遇到损坏内容会保留当前配置，不会覆盖正在编辑的文件。

| 字段 | 说明 |
| --- | --- |
| `autoFollow` | 是否保持游戏自带的自动跟随（默认 `true`，即**不开启锁定镜头**）。手动改成 `false` 才启用锁定：角色移动、切换角色、回合开始、刷怪、开大/战斗演出都不移动画面；玩家拖拽/按键移动自由相机仍按游戏原样。旧配置缺少这一项时会在启动时自动补上默认值 `true` |
| `zoomStep` | **每格滚轮**移动的米数（默认 20）。写坏（0 / 负数 / NaN）会退回默认值，不会变成「滚轮没反应」 |
| `zoomInMax` | 沿视线**向前**（放大）的最大米数（默认 120）。太大相机会穿进棋盘里 |
| `zoomOutMax` | 沿视线**向后**（缩小）的最大米数（默认 1500）。顶到极限后继续滚不会有任何变化 |
| `invertWheel` | 反转滚轮方向（默认 `false`：向前滚 = 拉近） |
| `smooth` / `smoothTime` | 平滑过渡（默认开，时间常数 0.12s）。关掉就是「一格一跳 / 一按一转」、立刻到位 |
| `ensureFarClip` | 拉远时按需把 `farClip` 抬到 `原值 + 偏移`，免得远处棋盘被裁掉；结束时还原（默认 `true`） |
| `requireReadyCamera` | 菜单 / 加载过渡期不响应滚轮与方向键（默认 `true`）。否则在主菜单按一下也会把过渡相机转来转去 |
| `maxReadyCameraHeight` | 占位相机判定用：朝向 `(0,0,0)` 且高度高于这个值（默认 500）就当成菜单/过渡相机 |
| `notify` | 是否弹「滚轮缩放 / 方向键旋转 / 已恢复」的屏幕提示（默认 `true`，每种各一条） |
| `restoreKey` | 复原键（默认 `F1`）。旧版的 `toggleKey` 会被继承过来 |
| `resetKey` | 第二个复原键（默认 `F2`）。`None` = 不用第二个键 |
| `rotateLeftKey` | 向左旋转地图的按键（默认 `LeftArrow`）。`None` = 关掉这个方向；键名与 Unity `KeyCode` 一致（如 `A`、`Q`） |
| `rotateRightKey` | 向右旋转地图的按键（默认 `RightArrow`）。`None` = 关掉这个方向 |
| `rotateSpeed` | 按住旋转键时的速度，**度/秒**（默认 90）。`0` = 不连续转，只保留点按 |
| `rotateStep` | 点按一次旋转键的最小角度，**度**（默认 15）。`0` = 关掉点按步进，只保留按住连续转 |
| `invertRotate` | 反转左右方向（默认 `false`：`→` 让视点向右转 / 地图往左转）。改成 `true` 就是「`→` = 地图向右转」 |
| `blockPanWhileRotate` | 旋转时抵掉游戏自己的左右方向键平移（默认 `true`）。改成 `false` 则旋转的同时地图也会被推走（方向仍按地图角度换算） |

## 4. 行为细节

- **滚轮缩放只改位置**：`autoFollow=true`（默认）时缩放只写相机位置，不写旋转、`FOV`、`nearClip`
  （`farClip` 只在 `ensureFarClip=true` 且拉远到可能裁掉远处时才临时抬高，交还时还原）。
- **旋转只加 yaw**：旋转时写「位置绕观察点转 + `yaw` 加同一个角度」，`pitch`（俯角）、`roll`（滚转）
  和 `FOV` 保持游戏原来的值。所以画面不会歪、不会变成俯视，只是棋盘转了个方向。
- **旋转中心**：取当前活动 vcam 的 `Follow` 目标 —— 就是相机正在看的那个点（自由相机对象 / 角色）。
  本作的 GM 相机（`Core.Camera.GMFreeCamera`）也是绕 `Follow` 目标转的，所以观察点会一直留在画面中心。
- **抵消方向键平移**：`blockPanWhileRotate=true` 时，按住旋转键的每一帧都会把 `Core.FreeCameraObject`
  的世界 `XZ` 拉回本帧开始前的位置（高度不动）。只对自由相机对象生效，且位置跳变超过 60m
  （游戏在换玩家/摆放演出）时不拦，改为重新取基准。
- **旋转后的平移方向**：游戏拖拽/键盘平移沿自由相机对象的**世界** forward/right，而画面已转
  `yawDelta`。mod 每帧把自由相机对象这一帧的实际位移绕基准点转 `yawDelta` 度再写回，于是
  旋转多少度、拖拽方向就跟多少度；没有旋转时完全不动自由相机。按住旋转键时这一帧位移被抵掉。
- **缩放基准**：默认模式每帧先读游戏写下的相机位姿，再在上面加「沿视线的前后偏移」与「绕观察点的旋转」；
  游戏自己在动（拖地图、跟角色、镜头过场）时偏移/旋转会跟着走，不会「锁死在一个点」。
  锁定模式则以锁定位置为基准叠加，所以缩放/旋转不会把固定镜头带回游戏当前的自动运镜位置。
  为了区分「相机里的值是我们写的」还是「游戏写的」，默认模式下会比较当前位姿与上次写入值：完全一致 =
  游戏这帧没动相机，就沿用上次识别出的基准（否则会在已经拉远/转过的位置再叠加一次，越滚越远、越转越多）。
- **偏移范围**：`[-zoomOutMax, +zoomInMax]`（正 = 向前/拉近）。顶到极限继续滚只返回原值，静默不刷提示。
- **旋转不封顶**：可以一直转；松开后角度会折回 `(-180°, 180°]`，画面完全不变，连续转很多圈也不会让精度变差。
- **自动交还**：缩放偏移回到 0、平滑收敛（容差 0.25m）**并且没有旋转**时自动停止接管 ——
  此刻相机里就是游戏自己的位姿，交还不会有任何跳变。有旋转时不会自动交还（否则地图会自己转回去）。
- **交还会写回一次位姿**：结束接管时会把「最后一次识别到的游戏位姿」写回相机一次（旋转过的话连朝向一起写回），
  并还原 `farClip`。这样即使游戏那边（例如 Brain 失活、镜头不动的时候）不重写相机，也不会把我们算出来的位姿留在相机上。
- **切场景 / 换相机**：一律清零偏移与旋转、结束接管，绝不把上一个场景的偏移/角度套到新相机上。
- **锁定模式下的旋转**：`autoFollow=false` 时旋转同样可用。按住旋转键不会被当成「玩家在平移自由相机」，
  所以固定镜头不会跟着漂；玩家真实拖拽时更新锁定值用的是「去掉缩放/旋转之后的游戏位姿」，
  不会把旋转角重复算进锁定值（否则会越转越多）。
- **关闭自动跟随（`autoFollow=false`）**：做三层保证：
  1. 把**角色相机**（Cinemachine vcam）的 `Follow` 换成一个固定锚点，锚点每个场景只取一次初始位置；
     换角色相机时提前把所有角色相机（包括正在混合切入的那台）都指向锚点，角色移动/切换角色都不会带动镜头；
  2. 在每帧最后（`PostLateUpdate`）把棋盘主相机的位置和朝向锁回固定值，所以回合开始、刷怪、
     自由相机运镜等游戏自动运镜不会移动画面。回合过渡/占位相机出现时**不释放锁定**，
     只有切场景才重置；
  3. 开大/战斗演出时游戏会禁用主相机、改用独立的 `PKMainCamera`。mod 会找出这类带
     `CinemachineBrain` 的演出相机，在它启用时记下开场机位并每帧写回，演出运镜也不会移动画面。
  玩家主动拖拽/按键移动自由相机时解除这一帧的主相机锁定，并把锁定位置更新到当前画面；之后切回角色相机不会跳回旧位置。
  切场景、卸载 mod 时会把原 `Follow` / `LookAt` 还原，并停止锁定。

## 5. 实现原理（为什么必须这么写）

本作实测（2026-09-20，国服）留下的两条硬约束，决定了实现方式：

1. **菜单 / 过渡期的 `CinemachineBrain` 可能挂在失活对象上**，靠 `VirtualCamera` 抢优先级不生效 ——
   缩放/旋转只有「每帧直接写主相机」可靠（详见 `docs/SDK-相机.md` §7）。战斗内角色相机的跟随
   仍由 Brain + vcam 驱动（这就是自动跟随能改 vcam `Follow` 的原因）。
2. **游戏自己的相机逻辑每帧都在写相机**，所以我们的写入必须排在它后面：
   `UpdateService` 的 `OnLateUpdate` 实际时机是 `PostLateUpdate`，正好在游戏 `LateUpdate` /
   Cinemachine 之后、渲染之前 —— 本帧渲染用的就是改过的机位。

另外几条：

- **游戏完全没用滚轮**：反编译 `AstralParty.Runtime.dll` 里没有任何 `Mouse ScrollWheel` /
  `mouseScrollDelta` 的读取（游戏自己的平移是鼠标左键拖拽 + 键盘），所以滚轮是「白拿」的一个轴，
  不存在和游戏抢操作的问题，也不需要拦截输入（SDK 的 Capture 本来也拦不住游戏，见 `docs/SDK-输入与光标.md`）。
- **滚轮只可能来自 Unity 后端**：SDK 的 Win32 后端没有滚轮实现，`InputService.GetMouseScroll()`
  先读 `Input.mouseScrollDelta`（原生每格 ±1），取不到再回退 `Mouse ScrollWheel` 轴（默认每格 ±0.1，
  已折算成格数）。两个都拿不到就恒为 0，日志里会有「滚轮没反应」的排查线索。
- **方向键会被游戏当成平移**：`Core.FreeCameraObject.HandleMoveCamera` 读 `Input.GetAxis("Horizontal")`
  （Unity 默认把 `←`/`→` 映射进去），再用 `CharacterController.Move` 推动自由相机对象。
  mod 只读输入、拦不住它，所以按住旋转键时在 `PostLateUpdate` 把自由相机对象拉回本帧开始前的位置，
  平移就不会累积。拉回/换算的是**挂着 `Core.FreeCameraObject` 的那个对象**
  （`CinemachineService.GetFreeCameraObjectTransform`），不是 vcam 的 `Follow` 节点 ——
  本作 `Follow` 可能是它的子节点，改子节点只会在父对象里积累局部偏移。
- **旋转后平移方向必须自己换算**：相机位姿是「游戏位姿绕观察点转 `yawDelta`」，但游戏平移用的是
  自由相机对象的**世界**轴；相机实际是沿未旋转的世界轴平移的，所以画面看起来会歪 `yawDelta`。
  mod 每帧取自由相机对象这一帧的位移 `v`，写回 `R(yawDelta) × v`（`FreeCameraMath.RotateAroundVertical`），
  画面上就仍然是想拖的方向。按住旋转键时 `v` 被置零，只保留旋转。
- **旋转方式与游戏的 GM 相机一致**：`Core.Camera.GMFreeCamera` 的转向就是「旋转 Follow 目标 +
  给 vcam 写同样的 yaw」。mod 不能改 Follow 目标（会连带改变游戏的移动方向），所以直接写主相机的
  「位置绕 Follow 目标旋转 + yaw 加同一个角度」，效果相同，而且只影响画面。
- **自动跟随来自角色 vcam 的 Follow**：反编译确认 `Core.Camera.CharacterCamera` 创建相机时只做
  `vCamera.m_Follow = _character.transform`。关掉自动跟随的第一层是把**角色相机**的 Follow
  换成固定锚点；锚点每个场景只落一次，换角色相机时只改 Follow、不移动锚点。相机混合开始时
  扫描全部 vcam，把正在切入的角色相机也提前锁到锚点，避免它先跟新角色走一帧。自由相机对象
  （`Core.FreeCameraObject`）用 `CinemachineService.IsFollowingFreeCamera` 区分：只有玩家
  自己拖拽/按键移动自由相机时锚点才跟着走，游戏事件运镜不会改掉固定镜头。
- **只改 vcam Follow 挡不住回合开始/刷怪**：这些流程会把自由相机对象搬到新位置，而角色相机
  此时并未接管，画面仍然会动。因此 `autoFollow=false` 时还会在 `PostLateUpdate` 最后把主相机
  的位置和朝向锁回固定值；只有玩家主动拖拽/按键移动自由相机的那一帧才解除锁定，并把锁定值
  更新到当前画面。两者叠加后，所有游戏自动运镜都不会移动画面。
- **回合过渡期间不能释放锁定**：游戏在回合开始/刷怪/演出时会临时把主相机挪到 `(0,0,0)` 或高处
  （占位/过渡相机），旧版把它当成"菜单相机"而释放锁定，结果镜头跟着游戏跑到新位置、再在新位置
  重新锁一次。2.4.5 起占位相机不再释放锁定，只有真正切场景时 `OnSceneLoaded` 才重置；
  因此回合开始/刷怪不会再出现"松一下再锁"的移动。
- **开大/战斗演出用的是另一台相机**：反编译 `BattleShowDirector.ActiveBattlePlatform` 会
  `PKCamera.EnablePKCamera()` 并把主相机 `enabled = false`，画面由独立的 `PKMainCamera`
  （`PKCameraManager`，自带 CinemachineBrain）渲染。只锁主相机时这台相机照样会做演出运镜。
  2.4.4 起通过 `CinemachineService.FindBrains()` 找出所有带 Brain 的相机，跳过主相机后，
  对这类演出相机在启用时记录第一帧位姿与 FOV/正交参数，之后每帧写回，把它冻结在开场机位。

## 6. 日志与自检

| 日志 | 含义 |
| --- | --- |
| `自由相机(滚轮缩放 + 方向键旋转)已就绪: … 旋转=LeftArrow/RightArrow (90°/秒, 点按 15°) …` | 初始化完成，打印实际生效的配置 |
| `自由相机: 开始接管相机(滚轮缩放/方向键旋转; 位置随缩放/旋转改写, 俯角/FOV 不动) 进入前: …` | 第一次滚轮/方向键触发了接管 |
| `自由相机校验(第60帧): … 偏移=…m 目标=…m 旋转=…° 目标=…° … 偏差=0m (写入生效)` | 写完立刻回读一致 = 写入生效；「游戏位姿」每帧在变 = 游戏自己的操作仍然有效 |
| `自由相机: 已恢复原来的视角 (按键 F1), 偏移 -300m -> 0, 旋转 45° -> 0` | 按复原键交还，缩放与旋转一起归零 |
| `自由相机: 偏移已回到原位, 自动交还相机` | 缩放回到原位且没有旋转，自动交还 |
| `自由相机: farClip 已还原为 …` | 抬过 `farClip`，已按快照还原 |
| `旋转地图: 找不到旋转中心(相机没有 Follow 目标), 暂停旋转; 缩放不受影响` | 当前相机没有 vcam Follow（极少见）；旋转被跳过 |
| `自由相机: 当前是菜单/过渡相机, 等进入棋盘后再滚/按方向键` | `requireReadyCamera` 挡住了菜单期操作 |
| `自动跟随: 已关闭, 镜头固定在当前角色位置 (x, y, z); 之后角色移动、切换角色都不会再移动镜头` | `autoFollow=false` 时每个场景首次接管角色相机；之后换角色/换角色相机不会再打这条 |
| `自动跟随: 已锁定主相机位姿 (x, y, z); 游戏自动运镜不会再移动画面` | 首次稳定到角色相机后记录固定镜头；之后只有玩家主动平移自由相机才会更新 |
| `自动跟随: 已冻结演出相机 <相机名> 于开场机位` | 开大/战斗演出切入 PKMainCamera 时，记录开场机位并开始冻结；每次演出启用一次 |
| `自动跟随: 无法改写角色相机的 Follow …` | 当前 vcam 不支持改写（理论上不会出现），本次启动内不再尝试 |

`自由相机校验` 只在接管的第 60 / 300 帧各记一次，不刷屏。

## 7. 排查

| 现象 | 先看什么 |
| --- | --- |
| 滚轮完全没反应 | 日志里有没有「自由相机: 开始接管相机」；没有就是滚轮没读到（`INPUT` 日志 + 上面的「滚轮只可能来自 Unity 后端」）；如果日志是「当前是菜单/过渡相机」，说明还在菜单/加载里 |
| 方向键不旋转 | 看日志里的「旋转=…」是不是 `LeftArrow/RightArrow`（`config.json` 里键名拼写、`None` 会关掉对应方向）；确认 `rotateSpeed` 与 `rotateStep` 没有都写成 0；如果日志是「当前是菜单/过渡相机」，说明还在菜单/加载里 |
| 旋转时地图还在平移 | `blockPanWhileRotate` 是不是被改成了 `false`；另外方向键只在自由相机由玩家控制时才会被抵消（角色相机/演出相机本来就不会被方向键推走） |
| 旋转后拖拽/键盘平移方向不对 | 已按当前地图角度换算（2.6.0 起）；确认游戏目录里是当前版本的 `FreeCameraMod.dll`。按住旋转键时平移本来就会被抵掉 |
| 点按一下几乎看不出来 | `rotateStep` 太小（默认 15°）；`rotateSpeed` 只影响「按住」，不影响点按 |
| 旋转后地图没有自己转回来 | 预期行为：旋转会保留，按 `F1`（或切场景）才归零 |
| 画面歪了 / 变成俯视 | 默认模式只加 yaw，不会改俯角/滚转；`autoFollow=false` 会锁定欧拉角。先确认 `AstralParty_ModLoader\mods\FreeCameraMod\` 下是 v2.6.0 的 dll + sidecar |
| 有接管日志但画面不变 | 看 `自由相机校验` 的「偏差」：> 0.5m 会额外打一条「自由相机位姿没写进相机」，说明这台相机拒绝外部写入 |
| 相机卡在缩放/旋转后的位置 | `F1` 复原；仍然卡住就看日志有没有「已恢复原来的视角」——若没有，多半是没读到按键（改键后确认键名拼写，写在配置里不受游戏改键影响） |
| 一滚就飞很远 | `zoomStep` 太大（例如把 20 写成 200）；`invertWheel` 只改方向不改步长 |
| 角色走路时镜头还是跟着走 | 确认 `autoFollow` 写的是 `false`（不是 `true`）；保存后等约 1 秒热重载，日志里应有「自动跟随已关闭」 |
| 切换角色时镜头还是会动 | 确认游戏目录里是 2.6.0 及以上的 `FreeCameraMod.dll`（2.4.0 会在换角色时重新落锚点，2.4.1 还没有主相机锁定）；日志应显示一次「之后角色移动、切换角色都不会再移动镜头」，之后不再重复 |
| 回合开始 / 刷怪 / 演出时画面还在动 | 确认是 2.6.0 及以上，且 `config.json` 里的 `autoFollow` 已手动改成 `false`（2.4.3 起默认不开启）；2.4.2 起会锁定主相机位姿，2.4.5 起占位/过渡相机不再释放锁定。玩家自己拖拽/按键平移自由相机的帧除外 |
| 开大 / 战斗演出时画面还在动 | 2.4.4 起会把 `PKMainCamera` 冻结在开场机位；确认 DLL 版本，并看日志有没有「已冻结演出相机」。如果你希望开大时**完全不切到演出相机**（留在棋盘视角、看不到开大动画），需要另一种实现，告诉我即可 |
| 关掉自动跟随后看不到角色了 | 这是预期行为（镜头完全停住，切换角色、回合开始、刷怪都不会跟过去）。用鼠标拖拽平移到角色附近；自由相机拖拽后镜头会停在新位置。把 `autoFollow` 改回 `true` 可恢复游戏跟随 |

## 8. 与旧版（v2.x）的差异

| | v2.x（已废弃） | v2.4.5 | v2.6.0 |
| --- | --- | --- | --- |
| 触发 | `F1` 开关（或 `autoActivate` 延迟自动进入） | 滚轮；进游戏不接管 | 滚轮 + 左右方向键；进游戏不接管 |
| 自动跟随 | 无此开关（始终跟随角色） | `autoFollow`（默认 `true`；`false` = 锁定镜头，角色移动/切换角色/回合开始/刷怪都不动） | 同 2.4.5 |
| 视角 | 抬高到 `height` 米 + `pitch` 俯角（**视角会变**） | 沿视线前后移动（**视角不变**） | 缩放沿视线前后移动、旋转只改 yaw（**俯角/滚转不变**） |
| 旋转 | 无 | 无 | `←`/`→` 绕观察点旋转地图（可改键/速度/点按步进） |
| 配方键 | `mode/height/heightStep/pitch/fov/boardHeight/aimDistance/autoActivate/…` | `zoomStep/zoomInMax/zoomOutMax/invertWheel/smooth/…` | 在 2.4.5 的基础上增加 `rotateLeftKey/rotateRightKey/rotateSpeed/rotateStep/invertRotate/blockPanWhileRotate` |
| 退出 | `F1` 还原进入时的快照 | `F1`（或滚轮回原位）交还「游戏自己的位姿」，`farClip` 按快照还原 | `F1`（或滚轮回原位且没有旋转）交还位姿（旋转过会连朝向一起还原） |

> 升级时旧键会在启动时自动删除并写入新的默认配置（只把旧版的 `toggleKey` 继承为 `restoreKey`），
> 不会被当成「配置损坏」备份成 `.bak`。
