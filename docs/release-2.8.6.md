# CesiumLoader 2.8.6

- 模组配置支持多语言说明：`config.json` 顶层新增保留键 `_comments`，为每个配置项提供简中、繁中、英文、日文说明。
  - Toys 的模组配置弹窗按界面语言显示说明，缺失时依次回退到同语系中文、英文、日文。
  - 第三方模组也可以只写一句字符串，所有语言共用。
  - 说明保存在配置文件末尾，Toys 保存配置时会原样保留；没有说明的旧配置界面保持不变。
- SDK 新增 `ConfigDoc`、`ModConfig.Describe()` 与 `ModConfig.SetDefault(key, value, ConfigDoc)`。模组初始化时补齐说明即可，已有用户值不会被覆盖，旧配置升级后会自动补上说明。
- 全部内置模组补齐配置项说明（简中 / 繁中 / 英文 / 日文），首次进入游戏或打开 Toys 配置页即可看到。
- 加载器 / SDK / CLI 版本统一到 2.8.6。

更新后重启游戏生效，已有模组配置与自定义值保留。
