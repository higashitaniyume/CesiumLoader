# CesiumLoader 2.5.1

- 战斗辅助在左侧所有玩家头像的昵称上方显示各自技能 CD，冷却上限跟随角色、模式和天赋。就绪显示绿色，冷却中显示黄色，可通过 `ShowSkillCooldown` 关闭。
- 修复战斗辅助配置页为空的问题，启动时补齐缺少的配置项并保留已有设置。
- 修复 SDK 旧式回调入口的 Mod 上下文注册，配置与日志归属对应模组。
- 新增内置岔路地块标记：PVE 三岔路相邻地块按邻接顺序显示红 A、黄 B、蓝 C 与地块 ID，支持配置关闭。
- 控制台遵循 Windows 默认终端设置；传统控制台支持置顶，Windows Terminal 窗口由终端管理。

更新后重启游戏生效，已有模组配置保留。
