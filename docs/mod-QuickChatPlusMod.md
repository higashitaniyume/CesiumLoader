# 快捷短语扩展 QuickChatPlusMod 1.0.0

战斗内点开快捷短语列表时，把游戏 Chat 配置里属于房间等待、结算和其他模式的既有短语一并显示出来。当前版本 PVE 列表通常为 16–19 条，扩展后每个 PVE 模式都是 32 条（同一模式内按 ChatID 去重）。

短语文本仍由游戏按 ChatID 查本地化表，发送仍走原版按钮，所以其他玩家即使没装本模组，也能看到同样的文字和气泡。

## 安装

需要 CesiumLoader SDK 2.8.6 或更高版本。把安装包中的 QuickChatPlusMod 文件夹解压到游戏 `AstralParty_ModLoader/mods/` 下，重启游戏。首次运行会在模组目录生成 `config.json`。

## 配置

修改模组目录的 `config.json`，保存后约 1 秒内自动热重载：

- `enabled`：总开关，默认 `true`；关闭后恢复游戏原版列表。
- `includeRoomChats`：把房间等待阶段的短语（准备、谢谢等）加入列表，默认 `true`。
- `includeResultChats`：把结算阶段的短语加入列表，默认 `true`。
- `includePvpModes`：也给标准 PVP、战役 PVP、非对称对抗、练习 PVP、无限火力、幸运星补全短语，默认 `false`，即只改 PVE 模式。
- `maxVisibleItems`：列表最多同时显示几条，超出的部分用滚轮或拖动滚动；默认 `16`，`0` 表示按屏幕可用高度尽量多，范围 `0`–`60`。

## 行为说明

- 覆盖 PVE、词条 PVE、战役 PVE、练习 PVE。战役 PVE 与练习 PVE 原版列表为空、点开无反应，启用后可以正常打开。
- 列表打开时若高度超出屏幕，会限制可视高度并开启滚轮 / 拖动滚动；列表贴近屏幕底部时会整体上移，保证所有条目都能翻到。
- 只在特定地图出现的短语（例如 82010、82014 的条目）会放开到所有地图；关闭模组后恢复原有地图限定。
- 同一模式内按 ChatID 去重：原版已经显示的短语不会重复出现。
- 列表中的每个条目都用游戏原有 ChatID，文本随客户端语言由 STRChat 本地化表渲染。
- 只改变本机的列表内容，不发送消息、不改动服务器数据；发送频率仍受原版按钮自带的冷却限制（当前版本为 600 毫秒）。
- 只能使用游戏配置里已有的短语。协议只传 ChatID，接收端按本地化表渲染，因此自己新增的自定义文本不会在别的客户端显示。
- 观战和新手房不显示聊天按钮，本模组在这些场景不生效。

许可：AGPL-3.0，与仓库内置模组一致。
