# CesiumLoader 2.6.0

发布日期：2026-10-23

- 新增配置热重载：变速、自由相机、战斗辅助、岔路地块标记、自动感谢、手牌查看、诊断工具在游戏运行中修改 `config.json` 后自动应用，无需重启游戏。
- 配置解析支持 `//` 与 `/* */` 注释，Toys 生成的带注释空配置可直接读取。
- 热重载遇到写到一半或损坏的配置时保留当前设置，不覆盖正在编辑的文件；同一份坏内容只提示一次。
- 新增内置模组「回合置前」：轮到自己回合、选择筹码、战斗询问、战斗出牌、攻击骰或防御选择时把游戏窗口切换到前台，窗口已在前台时不打扰；可在配置中开关并调整冷却。
- 新增窗口置前控制文件通道，可在 `doorstop_config.json` 中用 `windowControlEnabled` 关闭。
- 加载器、SDK 和 CLI 版本统一为 2.6.0；分发 DLL 与同次构建 PDB 成对更新。

角色皮肤、卡面皮肤等需要重新加载资源的模组仍需重启游戏后生效。
