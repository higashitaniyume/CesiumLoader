## ABI 防回归

新增 `tests/CesiumLoader.SDK.Tests/DistributionAbiTests.cs`，直接读取分发 DLL 的 IL 与当前游戏 DLL 的枚举元数据，不执行 Unity 代码：

- 7 个参数用例覆盖 SDK Names 和 CardSkin 中的本地化枚举常量，防止旧 DLL 混入 dist；在强制重编前全部失败，之后全部通过。
- 1 个用例读取 SDK 和全部内置 mod 的 CodeView GUID 与便携 PDB ID，确认符号和 DLL 配对。
- HandViewer 的 Render 内 3 处 Card 常量另以同样的 IL 检查临时加入参数验证并通过；由于它的 dist 不入库，不把此本地产物依赖留在常规 SDK 测试中。

可重复运行：

```powershell
pwsh -NoProfile -File tools/package-modloader.ps1
dotnet build tests/CesiumLoader.SDK.Tests/CesiumLoader.SDK.Tests.csproj -c Release -t:Rebuild
dotnet test tests/CesiumLoader.SDK.Tests/CesiumLoader.SDK.Tests.csproj -c Release --no-build
```
